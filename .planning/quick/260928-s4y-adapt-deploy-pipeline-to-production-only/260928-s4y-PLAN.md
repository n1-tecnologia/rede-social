- `hookConfig.validate` returns immediately when `enabled = false` (no `uri`, no `secrets` required). The push body sets `HookSendEmailEnabled=false` and sends `uri`/`secrets` only when enabled. So the remote block needs only `enabled = false`; the inherited base `uri`/`secrets` are never validated nor sent.

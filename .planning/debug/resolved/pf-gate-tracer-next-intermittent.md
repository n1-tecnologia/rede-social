## Resolution

root_cause: "A race between two navigations that the spec arrangement makes near-certain. The sign-in leaves the /inicio shell open; ~16 ms after it lands, the spec flips the gate by direct SQL and issues `page.goto(/post/{id})`; the shell's websocket then joins (SUBSCRIBED), LiveCountersProvider refetches /api/me/counters on every join, the API gate (live membership lookup) answers 403 PROFILE_FORM_PENDING, the BFF maps it to the bare `/completar-perfil?t=<tenant>` and LiveShell.landOnFormFlow does `window.location.assign` of it, which cancels the in-flight document navigation (ERR_ABORTED ~30 ms after it started). The server render of /post/{id} (requireBootstrap, the x-rede-path header, the g1y slot) never runs in the failing repeats, so quick g1y fixed a path that was not the one failing. The server-render path is correct: it passes 6 of 6 once the shell is gone. Product facts that remain: an open-app redirect (counters refetch or a server action such as FeedVideo's token re-mint) is destination-less by decision (12-11, g1y), which is fine for a member who is idle on a page, and there is one narrow real window: a member whose app is open in the background while the gate flips and who then taps a link or notification (the foreground visibilitychange refetch and the link navigation race; the refusal arrives first, ~30-100 ms, and she lands on the form and then on /inicio instead of the post). The page cannot know the target of a browser-initiated navigation in flight, so that window has no deterministic cheap fix; a timing grace before assigning would be a heuristic that breaks on a cold dev compile."
fix: "apps/web/e2e/profile-form-gate.spec.ts test 1 (commit 68b802cc): after signing in and before the gate appears, `page.goto('about:blank')` closes the live shell, so the deep link is a cold open decided by the server (the path D-583 describes); and the deep link uses a plain `page.goto` instead of `gotoWhileRedirected`, so a cancelled navigation can never be absorbed silently again. No product code changed."
verification: "Before: 4 of 6 repeats failed (Received null), traces of repeats 1, 2, 3, 5 read: goto ERR_ABORTED, post never rendered, bare form wins. After: `playwright test profile-form-gate.spec.ts --project=mobile-chromium -g 'deep link' --repeat-each=6` = 6 passed (20.9 s); then the whole gate spec once = 6 passed (21.0 s). biome check on the spec clean.

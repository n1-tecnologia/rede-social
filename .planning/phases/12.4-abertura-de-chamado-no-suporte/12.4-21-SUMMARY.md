# Phase 12.4 Plan 21: Staff inbox reconcile, member pane adopts the new case, Anteriores closed total Summary

**A fresh page 1 now replaces the window of the server order it covers (pure `reconcileInboxPage` over the API's own `lastMessageAt`), so a case that left a tab leaves the staff list on the next refetch; the member pane adopts the case a send opened; "Anteriores" shows the closed total.**

## Performance

- Tasks: 3 (1 tracer, 2 auto), commits: 2 feature commits plus the close-out commit
- Files changed: 12 (no migration, no route, no contract key, no catalog string)

## Accomplishments

- **T7 / WR-01 (tracer).** `InboxRowView` carries `lastMessageAt` as an order key only. `reconcileInboxPage(current, fresh, { holdsOnlyPage1, hasMore })` returns `{ items, whole }`: whole (page 1 only, the answer ends the view, or an empty answer) makes the list exactly the fresh page; otherwise the fresh rows come first and the loaded rows that sort strictly after the last fresh row stay in their order. `SupportInbox.refreshPage1` applies it, resets the page count and cursor on a whole answer and clears the inline page-error line when the view ends. A failed read keeps every row; the one-in-flight, one-queued coalescing and the left-view guards are untouched. The old keep-everything `mergeTop` is gone.
- **WR-02.** When a member send answers a conversation id different from the one the pane holds, the pane switches before `refreshCase()`: ref and state id, catch-up cursor and read mark reset to 0, older-page flag and count reset, the message list replaced by the answered view, the bar built from the answer. `catchUp` and `refreshCase` discard an answer for a conversation the pane left (the header reader re-arms for the new id). A staff pane never switches.
- **WR-03.** `previousCount = Math.max(total, items.length)`, with no subtraction of the current case. The `myCasesPageSchema` docblock, `MyCasesPageView.total` and the BFF handler docblock say `total` counts closed cases; the BFF and action fixtures model `total` as the closed count.

## Sampling Rate

- **After every task commit:** the touched package's unit suite plus the one pgTAP file or the one integration file the task names (apply migrations with `pnpm supabase migration up` only).
- **After every plan wave:** `pnpm supabase test db` (all pgTAP), the chat, isolation, realtime, notifications and dashboard integration files, `pnpm turbo test --concurrency=4`.
- **Before `/gsd-verify-work`:** the full `verify` chain except the parts that need Igor's word (`db:reset`, `db:seed`, e2e), plus `chat-cases.spec.ts` on his run.
- **Max feedback latency:** ~120 seconds for a task; a wave may take several minutes.

## Sampling Rate

- **After every task commit:** the single targeted file (seconds); SQL tasks the single pgTAP file; contract or `requireAuth` seam changes add `TURBO_CACHE=local:r pnpm turbo typecheck --filter=@rede-social/core --filter=@rede-social/api`. Web tasks also run the sketch grep (`grep -q '^approved: true' .planning/sketches/019-phase-12.2-designed-screens/README.md`) and `bash scripts/check-ui-literals.sh`.
- **After every plan wave:** `TURBO_CACHE=local:r pnpm turbo typecheck test --continue --concurrency=4`, then pgTAP once the SQL plans landed, then the new integration files one by one.
- **Before `/gsd-verify-work`:** full suite green, plus Playwright under the disk watchdog.
- **Max feedback latency:** 60 seconds for a task-level check.

<objective>
The design gate every Phase 08.2 UI plan waits on (D-365, Phase 2 D-33, UI-04, and the UI-SPEC's own instruction that the product owner approves the sketch before any UI task starts).

**As a** product owner of the platform, **I want to** see the store, the purchase pop-up, the locked community and the store admin screens drawn before they are built, **so that** they ship in the prototype's language and with the copy I signed off on. Derived from D-365; the ROADMAP goal line is not a user story.

The seven surfaces have no prototype screen (`reference/frontend-design/` has no store, checkout, price, buyers or locked-community UI). Everything they reuse — `CommunityCard`, `CommunityHeader`, `PostCard`, `ConfirmDialog`, `BottomSheet`, `Chip`, `StatusPill`, the TopBar — is drawn only as context. This plan runs in wave 1 beside the API tracer, so the review happens while the API is built; backend, schema and gate plans (03-06) never wait for it.

Output: sketch 008 (one self-contained `index.html` and a README), its manifest row, and the user's recorded approval.

**Commits.** No `Co-Authored-By` trailer (project memory: public repository).

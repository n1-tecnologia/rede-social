## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The TopBar logo slid under the Loja slot at 320px (E01 overflow)**
- **Found during:** Task 1 (the new E01 case failed: the logo image's right edge was at 144px, while its link ended at 100.5px).
- **Issue:** The logo box cap `min(11rem, 100vw - 12rem)` assumed two TopBar slots. The store's third slot needs about 204px on the right, and the wrapper is `shrink-0`, so a 128px wordmark overflowed its 84px link.
- **Fix:** The topbar box is `min-w-0 shrink`, which overrides the wrapper's `shrink-0`. The `object-contain` image scales down inside it. Wider screens keep the cap.
- **Files modified:** packages/core/ui/TenantLogo.tsx
- **Verification:** E01 passes, and so do `shell.spec.ts` and the rest of the suite in the final gate.
- **Committed in:** 9992c1a

**2. [Rule 3 - Blocking] `pnpm lint`, the gate's first step, failed on the formatting of 08.2-01's `money.test.ts`**
- **Found during:** Task 3, before the first run.
- **Issue:** `deferred-items.md` attributed the contracts lint failure to `text.test.ts`, but those two findings are warnings. The one error was the formatter refusing the layout of `packages/contracts/tests/money.test.ts`.
- **Fix:** `biome format --write` on that file only. The deferred entry is marked resolved.
- **Committed in:** 25b5cf7

**3. [Rule 1 - Bug] Two Módulos specs still counted seven switches (platform-toggle path)**
- **Found during:** Task 3, run 1. `platform-domains.spec.ts` test 6 and `phase2-smoke.spec.ts` test 4 failed on both projects: expected 7 switches, received 8.
- **Issue:** 08.2-05 added `store` to `TOGGLEABLE_MODULES`, but only `platform-tenants.spec.ts` was re-run then.
- **Fix:** The specs count eight switches, assert that `store` (Loja) is off for a new tenant, and expect `Desativado` 1, then 2 after the Feed toggle.
- **Committed in:** a0a4683

**4. [Rule 1 - Bug] The phase 8 smoke lost a composer fill to hydration (feed path)**
- **Found during:** Task 3, run 1 (mobile, criterion 3: "Publicar" stayed disabled after the fill).
- **Issue:** The spec filled `#composer-caption` before the composer hydrated. 08.2 did not touch the composer, and the case passed in 4 of 4 isolated repeats.
- **Fix:** The fill is retried inside `expect(...).toPass()` until "Publicar" enables.
- **Committed in:** a0a4683

**5. [Rule 1 - Bug] The like pulse timer outlived its button (feed path)**
- **Found during:** Task 3, run 2. The module-feed unit stage failed with `ReferenceError: window is not defined` from `LikeButton.tsx:190`, which 08.2-09's `post-card-readonly.test.tsx` triggered after teardown.
- **Fix:** A cleanup effect clears the 220 ms timer on unmount.
- **Verification:** module-feed passed 247/247 three times in a row.
- **Committed in:** 4663adb

**6. [Rule 1 - Bug] AUTH-06 aborted goto (media playback-token path, recorded by 08.1)**
- **Found during:** Task 3, run 1 (mobile) and run 6 (both projects): `page.goto('/inicio')` failed with `net::ERR_ABORTED`.
- **Issue:** This is the 08.1 deferred race. The open Início's playback-token action receives the 403 and redirects to the blocked flow while the test navigates. It touches a media path, so it could not be deferred.
- **Fix:** Step 3 tolerates exactly `ERR_ABORTED`. The next line still asserts the suspended screen and the cleared cookies.
- **Verification:** 24/24 with `--repeat-each 4`. The entry in the 08.1 `deferred-items.md` was left untouched (08.1's file); this commit resolves it in practice.
- **Committed in:** 42195cd

**7. [Rule 1 - Bug] The cover preview could show a revoked blob (store, communities and events forms)**
- **Found during:** Task 3, run 7. E11 failed on mobile: the local preview image never loaded, and the trace shows `blob:… net::ERR_FILE_NOT_FOUND`.
- **Issue:** `useCoverPreview` created the URL at pick time and revoked it in a mount-only cleanup. Any cleanup React runs while the form stays mounted therefore revoked the URL still on screen.
- **Fix:** The URL is created and revoked per effect run, keyed on the shown file. A new unit case hides and shows an `<Activity>`, and it fails on the old hook (checked by swapping the file back temporarily).
- **Verification:** web unit suite 111 files / 2369. The store and comunidades image cases passed 24/24 twice. The final gate passed.

- **Committed in:** a8d645b

**9. [Plan wording] DEPLOY.md's migration path**

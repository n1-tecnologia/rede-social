# Phase 08.2 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.
> Register = union of the `<threat_model>` blocks of 08.2-01..12 (54 threats). Audit depth: ASVS L1 (grep-level, each mitigation found in the cited file); suites were not re-run, VERIFICATION already ran pgTAP 348 and integration 121 after the review fixes.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| browser/BFF → API | store bodies, path ids and tenant host header are attacker-controlled for a direct caller | purchase/grant bodies, ids |
| API (api_user, tenant lane) → Postgres | tenant claims per transaction; RLS is the structural guard; definers bypass RLS as owner | tenant data, ledgers |
| kernel seam → module body | feed policies call kernel-named gate functions supplied by the store | gated post/comment visibility |
| worker → notifications/push | resolvers must honour the gate | excerpts of locked posts |

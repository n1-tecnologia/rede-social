## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 5.0.0 (module, api, contracts, web units, API integration); pgTAP via `supabase test db`; Playwright 1.63.0 |
| **Config file** | per-package `vitest.config.ts` (Vitest 5 does not walk up; `packages/modules/store/vitest.config.ts` is new), `apps/web/playwright.config.ts`, `supabase/tests/000-helpers.sql` |
| **Quick run command** | `pnpm --filter @rede-social/module-store test` and `pnpm --filter @rede-social/api test` (plus `pnpm supabase test db` when a migration or policy changed) |
| **Full suite command** | `pnpm lint && TURBO_CACHE=local:r pnpm turbo typecheck test`, then `pnpm supabase test db`, then `pnpm test:integration`; phase gate `pnpm verify` |
| **Estimated runtime** | ~90 seconds (quick); ~600 seconds (full, without e2e) |

`pnpm test:integration -- x` does not filter; run one file with `pnpm --filter @rede-social/api exec vitest run tests/integration/<file>.test.ts`. Run pgTAP before integration; reset + seed between runs if a run left residue.

---

## Sampling Rate

- **After every task commit:** the touched package's quick run (module-store / api unit / web vitest), plus `pnpm supabase test db` when a migration or policy changed
- **After every plan wave:** the full suite command, sequentially (never while another session uses the local Supabase stack)
- **Before `/gsd-verify-work`:** `pnpm verify` green (e2e included); the two-tenant isolation suite with the shared-identity fixture (SC 8) is the exit gate
- **Max feedback latency:** 600 seconds

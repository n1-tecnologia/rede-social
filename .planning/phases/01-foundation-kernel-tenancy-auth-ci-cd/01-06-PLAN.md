## Phase Goal

**As a** person invited by an organisation that runs a Rede Social community (a tenant), **I want to** sign up through that organisation's public link, log in with e-mail and password, stay logged in, recover my password and log out, **so that** I reach my organisation's private community at my organisation's own web address and the API only ever serves my organisation's data.

<objective>
Make "enabled modules" real for the member: `tenant_modules` rows (D-16) seeded per D-17, a tenant-keyed flags cache, the `requireModule` guard (404 when disabled), `requireRole`, the platform lane for `super_admin` (`platform_admins`, ROLE-01) — accepted only off tenant hosts (D-23) — and `/me/bootstrap` returning enabled modules in nav order plus role permissions. The platform host's `/inicio` placeholder (D-21) becomes API-authorised here: it lists the tenants from `GET /v1/platform/tenants`, and a non-admin session on that host is signed out. The registry is composed in `apps/api` so `@rede-social/core` never depends on a module (MOD-02 boundary); 01-07 registers the example manifest.

Purpose: ROLE-06 (authorization per route by role + enabled modules), ROLE-01 (`super_admin` outside memberships), MOD-02 (registry contract between kernel and modules), TENANT-01 (platform host reserved for `super_admin`, D-21/D-23).
Output: `tenant_modules` + migration, flags cache, three middlewares with the host rule, registry composition, bootstrap modules/permissions, platform route + contract, platform-host web slice, seed extension (hosts kept, D-24), unit + integration + e2e tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authenticated member → module routes | Flag + role decide access per tenant |
| Any token → `/v1/platform/*` | Cross-tenant admin lane; must be `platform_admins` only |
| In-process cache ↔ DB | Stale flags are tolerated for ≤ 30 s; stale membership never |

|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Elevation of privilege | `/v1/platform/*` | critical | mitigate | `requireSuperAdmin` verifies the JWT and reads `platform_admins` via admin lane per request; tenant admins get 403 (integration test) |
| T-06-02 | Information disclosure | disabled module routes | medium | mitigate | 404 `MODULE_DISABLED` (existence not confirmed); adjacency tests cover missing vs disabled rows |

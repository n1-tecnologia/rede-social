## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub OIDC → GCP STS | Only this repository may impersonate the deploy SA |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-01 | Spoofing | WIF provider | critical | mitigate | `attribute-condition` pins `assertion.repository` to `<owner>/rede-social`; no JSON keys exist |
| T-11-02 | Elevation of privilege | runtime SA | high | mitigate | Separate runtime SA with `secretAccessor` only; deploy SA has no secret access |

| T-11-04 | Tampering | recovery-link redirect on previews | medium | mitigate | Wildcard `https://*-<team>.vercel.app/**` only on staging; production allows exactly `app.seusistema.com` (RESEARCH §Pitfall 8) |
| T-11-05 | Spoofing | HS256 tokens on hosted projects | high | mitigate | JWKS check + rotation checkpoint before the first deploy |
| T-11-06 | Information disclosure | `NEXT_PUBLIC_*` in previews | low | accept | Only URL + publishable key are public by design |
</threat_model>

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 5.0.0 (unit, integration, web), pgTAP via `supabase test db`, Playwright 1.63.0 (e2e) |
| **Config file** | per-package `vitest.config.ts`; `apps/api/vitest.config.ts` reads `.env.local` for integration |
| **Quick run command** | `pnpm --filter @rede-social/module-events exec vitest run tests/contracts.test.ts` (and the sibling package or single file the task touched) |
| **Full suite command** | `pnpm verify` |
| **Estimated runtime** | quick under 30 s; integration needs the local stack; `pnpm verify` is long (run once at the exit gate) |

---

## Sampling Rate

- **After every task commit:** Run the single package or file command from the map below.
- **After every plan wave:** `pnpm supabase test db` first, then `pnpm --filter @rede-social/api exec vitest run tests/integration/<touched files>` (pgTAP before integration, one local stack; `test:integration -- x` does not filter, use `exec vitest run <file> -t "<title>"`).
- **Before `/gsd-verify-work`:** `pnpm verify` green; real-device and hosted rows stay manual.
- **Max feedback latency:** 30 seconds for unit and web commands.

## Excluir evento

### Which events can be deleted

| Option | Description | Selected |
|--------|-------------|----------|
| Qualquer evento (Recomendado) | Active, cancelled or past, with or without presence; the confirmation says confirmations and check-ins are kept | ✓ |
| Só evento sem check-in | A past event with a check-in could never leave the app (it cannot be cancelled any more) | |
| Só evento cancelado | Past events are locked as cancelled, so old ones would stay forever | |

**User's choice:** Qualquer evento.

### Notice to people who confirmed

| Option | Description | Selected |
|--------|-------------|----------|
| Nenhum, igual ao cancelar (Recomendado) | Cancel is silent (D-201, D-214), so delete follows it | ✓ |
| Avisar quem confirmou | New notification kind with copy and preferences | |

**User's choice:** Nenhum.

### Presence of a deleted event in the dashboards

| Option | Description | Selected |
|--------|-------------|----------|
| Continua valendo para o membro (Recomendado) | Member-side queries do not join events today, so nothing changes | ✓ |
| Deixa de contar | Needs a join with events in the member queries | |

**User's choice:** Continua valendo para o membro.

### What a member sees on a deleted event's link

| Option | Description | Selected |
|--------|-------------|----------|
| A tela de não encontrado de hoje (Recomendado) | Same 404 as an invalid or another tenant's link | ✓ |
| Mensagem própria "Este evento foi excluído" | Needs a distinguishable status and a new screen | |
| Esconder também os avisos antigos | Filter the bell list by event, which it does not know | |

**User's choice:** A tela de não encontrado de hoje.
**Notes:** This reverses the Phase 6 rejection of deleting events, by the client's request in the FRONT.pdf.

## Excluir comunidade

### A Loja product still unlocks the community

| Option | Description | Selected |
|--------|-------------|----------|
| Recusar e listar os produtos (Recomendado) | Names the products, archived ones do not count | ✓ |
| Excluir e ignorar o vínculo | Product keeps selling and unlocks nothing | |
| Excluir e arquivar o produto | Touches the catalogue unasked | |

**User's choice:** Recusar e listar os produtos.

### The community's publications

| Option | Description | Selected |
|--------|-------------|----------|
| Somem com ela (Recomendado) | Gone from Início, Reels and the post page, kept in the database | ✓ |
| Passam para o Início | Becomes tenant-wide content, and a locked community's posts would open to everyone | |

**User's choice:** Somem com ela.

### Confirmation

| Option | Description | Selected |
|--------|-------------|----------|
| Diálogo simples nos dois (Recomendado) | The `ConfirmDialog` that "Reativar comunidade" already uses | ✓ |
| Digitar o nome só na comunidade | New field in the dialog | |
| Digitar o nome nos dois | More friction for a test event | |

**User's choice:** Diálogo simples nos dois.
**Notes:** Highlights, pinned stories and membership rows are hidden by read filters, not erased; this was left to Claude (no question asked) because `community_members` has no rows today.

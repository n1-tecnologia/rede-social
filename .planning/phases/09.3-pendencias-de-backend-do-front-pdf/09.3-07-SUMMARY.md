# Phase 09.3 Plan 07: Delete event control Summary

**The event form's and the cancelled notice's "Excluir evento" placeholders became a live ConfirmDialog control that deletes through DELETE /v1/events/{id}, toasts and replaces the history with /eventos, and a deleted event's link is the existing not-found screen for admin and member.**

## Accomplishments

- `DeleteEventControl` island (model: `CancelEventControl`): danger trigger, `ConfirmDialog` with fixed catalog copy, three outcomes (success, 404 race with an info toast, failure with an error toast and the page kept), `router.replace('/eventos')`, no title anywhere.
- `deleteEvent` lib call and `deleteEventAction` in the `statusAction` shape: malformed id refused as `generic` before any request, `redirect` outside the try/catch, `revalidatePath` for `/eventos`, `/eventos/meus`, `/eventos/{id}` and `/inicio` only after success.

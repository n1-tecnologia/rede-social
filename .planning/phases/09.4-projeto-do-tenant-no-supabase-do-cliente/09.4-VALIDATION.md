## Sampling Rate

- **After every task commit:** the single targeted Vitest file(s) plus `pnpm turbo typecheck` for tasks that change a seam signature (`ProjectProvider`, `ProjectRecord`, `ProjectProviderError`).
- **After every plan wave:** the layer commands for the touched layers, `pnpm supabase test db`, `pnpm boundaries:negative && pnpm guard:lanes`.
- **Before `/gsd-verify-work`:** full suite green; the hosted proof rows stay `pending` until Igor writes `passed`, so the phase closes `human_needed`, never green, while any row is pending (09.2 assumption A-25-1).
- **Max feedback latency:** 30 seconds for the per-task check.

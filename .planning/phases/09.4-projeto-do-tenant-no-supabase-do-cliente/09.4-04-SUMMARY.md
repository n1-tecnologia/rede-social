## Findings the drawing recorded for the gate (README section "Achados do proprio desenho")

- **F-1** Header pill "Banco: Pronto" versus UI-D-541, which shows "Banco: {estado}" only when the database is not Pronto. The sketch draws only combinations that can occur.
- **F-2** UI-D-560 says the header Token pill shows for anything other than Valido, but UI-SPEC row E08 and the chip exclude Nao verificado. The sketch follows E08 and draws no header pill for it. Needs a one-line reconciliation in the UI-SPEC or the code plan.
- **F-3** The open "Como criar o token" title is not defined in the contract. The sketch uses 14px/700, secondary colour.
- **F-4** `[PENDENTE-PERMISSOES]` is drawn literally in step 3 of "Como criar o token". Approving the drawing does NOT approve the permission list. A catalog test must fail while the marker exists; plan 17 replaces it after Igor's probe (OQ-1). Delivery blocker.
- **F-5** The brand picker also recolours the panel, in this sketch only.
- **F-6** Measurements were taken with a fallback font: Manrope was not installed where the file was opened, so text widths at 320px are approximate and should be rechecked in the real app.
- **F-7** The shipped SegmentedControl has a fixed 44px height and whitespace-nowrap, while UI-D-549 needs two-line labels at 320px. The code needs a variant; plan 14 must handle it.

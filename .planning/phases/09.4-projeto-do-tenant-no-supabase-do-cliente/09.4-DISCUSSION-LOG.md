## Token errado: o que o sistema recusa

### One permission list or two (create vs maintain)?

| Option | Description | Selected |
|--------|-------------|----------|
| Uma lista só (Recomendado) | One step-by-step, one token serves creating, maintaining and the break-glass reissue; includes API Key Secrets so no manual access | ✓ |
| Duas listas: criar e manter | Full token to create, a smaller one to replace later; two how-tos, and the break-glass reissue stops working with the smaller token | |

**User's choice:** Uma lista só.
**Notes:** The question text said 12 permissions while naming 13; corrected to 13 right after and in CONTEXT D-569.

### How is an account-wide token refused?

| Option | Description | Selected |
|--------|-------------|----------|
| Prefixo + teste (Recomendado) | Refuse unless the token starts with `sbp_fc`, and also try listing the account's projects: if it works the token is broad and refused | ✓ |
| Só o prefixo | Simple, no extra call, breaks if Supabase changes the format | |
| Só o teste | Behaviour-based, but the list call becomes a 21st operation | |

**User's choice:** Prefixo + teste.

### When is the customer's organisation (the pin) stored?

| Option | Description | Selected |
|--------|-------------|----------|
| Na primeira leitura (Recomendado) | Read from the project with the token at registration and stored; later changes become "Organização diferente"; no extra field | ✓ |
| Você confere antes | The Resumo shows the organisation read and Igor confirms before creating (a new Resumo line the UI-SPEC lacks) | |

**User's choice:** Na primeira leitura.

### If the plan (Free/Pro) cannot be read with a project-scoped token?

| Option | Description | Selected |
|--------|-------------|----------|
| Só informar (Recomendado) | Researcher looks for a way to read it; if found, refuse Free; if not, show "Não informado" and do not block; Pro stays the operator's responsibility | ✓ |
| Exigir sua confirmação | A "Confirmo que o projeto está no Pro" checkbox when the plan cannot be read (changes the approved UI-SPEC) | |

**User's choice:** Só informar.

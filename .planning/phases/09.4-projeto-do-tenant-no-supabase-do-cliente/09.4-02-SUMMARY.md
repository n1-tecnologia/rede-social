## Accomplishments
- `platform.projects` gained `owner` (default `platform`), `org_slug`, `mgmt_token_sealed` and `mgmt_token_expires_at` with `projects_owner_chk`, `projects_org_slug_chk` and `projects_owner_token_chk`; every existing row satisfies the defaults, so an old API on the new database keeps working.

language sql stable security definer set search_path = '' as $$
  select case
    when app.tenant_role() in ('admin_tenant', 'support_tenant') then '{}'::uuid[]
    else (
      select coalesce(array_agg(distinct l.community_id), '{}'::uuid[])
        from public.store_product_communities l

## Shared Patterns

### Gate seam (database decides, service refuses first)
**Source:** `packages/core/db/community-gate.ts`, `app.community_locked_ids()`. Apply to like, comment, post, story-save. The service refuses with 403 before any write; RLS is the backstop; both call the same SQL function.

### Fail-closed definers
Empty `search_path`, `security definer`, `revoke ... from public`, `grant execute ... to authenticated`, strict `=== true` on the TS side, null role denies.

### Strict contracts
All touched Zod schemas are `.strict()`; every new key `.optional()` and emitted only when it differs from the default; contract tests in `packages/modules/communities/tests/contracts.test.ts` pin `actions`.

### Neutral refusal
Bare `ApiError(403, 'FORBIDDEN')` with no `details` (does not leak product or flag), unlike the locked case which carries `{ access: COMMUNITY_LOCKED }`.

### Constraints for every DB executor prompt
Every `supabase migration` command takes `--local`; never `db reset` or seed; migrations ordered columns -> functions -> gates.

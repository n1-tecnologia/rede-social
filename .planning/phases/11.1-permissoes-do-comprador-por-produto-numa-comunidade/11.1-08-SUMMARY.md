# Phase 11.1 Plan 08: feed service half of buyer permissions Summary

**The feed service now refuses like, unlike, comment, reply and comment hearts with one bare 403 before any write (a missing flag and a revoked entitlement are byte-identical), the buyer's post path is limited to 30 attempts an hour, and each post carries the viewer's own `community.actions` only when something is withheld.**

## Performance

- **Duration:** 17 min
- **Started:** 2026-11-25T12:36:00Z
- **Completed:** 2026-11-25T12:53:00Z
- **Tasks:** 3 (one tracer, two auto)
- **Files modified:** 6 (service, README, limits, the new integration file, the 242 pgTAP file, the baseline note)

## Accomplishments

- `assertPostInteractive` gained an optional `action`. The same select that reads the locked list now reads `app.community_action_denied_ids(action)`, and a denied post is a `403 FORBIDDEN` with no `details`, after `community_locked` and the hidden-post 404 or `follow_required`. `listComments` passes nothing, so reading is never reduced.
- Comment hearts, which had no guard, take one pre-read of the comment's post community. A story comment has no post, so it skips the test and still answers 400 `story_comment_not_likeable`.
- A member 42501 on the like, comment and heart writes (a revoke committing between the guard and the write) is the same bare 403; a staff 42501 stays a 500. Proved with a deterministic two-connection race.
- `memberCommunityPostLimiter` (30 per hour, tenant plus user) is consumed only in the buyer branch, every attempt counted, a refused one included; `createPost` needed no new route.
- `postProjection` selects `(select app.community_buyer_scope()) -> p.community_id::text` as an InitPlan, and `toPost` emits `community.actions { like, comment, share }` only when the viewer has an entry with at least one false flag.
- A buyer's `visibility = 'community'` post is on the community page and absent from Inicio, Explorar and the Reels lane (a ready video included); the worker resolver answers no intent for it and no notification row exists.

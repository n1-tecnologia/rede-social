> Per-phase validation contract for feedback sampling during execution. Seeded from the `## Validation Architecture` section of `11.1-RESEARCH.md`; the planner fills the task ids in the map below once the plans exist.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 5.0.0 (unit and module), API integration (Vitest against the live local stack), pgTAP via `supabase test db`, Playwright 1.63.0 |
| **Config file** | per-package `vitest.config.ts`; `apps/web/playwright.config.ts`; pgTAP files in `supabase/tests/` (next free number **241**) |
| **Quick run command** | `bash scripts/supabase.sh test db supabase/tests/000-helpers.sql supabase/tests/241-buyer-permissions.sql` (SQL layer); `pnpm --filter @rede-social/api exec vitest run tests/integration/buyer-permissions.test.ts` (API); `pnpm --filter @rede-social/module-store test` (module); `pnpm --filter @rede-social/web exec vitest run lib/store-permissions.test.ts lib/feed-view.test.ts` (web, pure layer) |
| **Full suite command** | `pnpm lint && pnpm turbo typecheck build test --concurrency=4`, then `pnpm boundaries && pnpm check:static-routes`, then `bash scripts/supabase.sh test db` (BEFORE) `pnpm test:integration`, then `pnpm e2e` |
| **Estimated runtime** | quick: 10 to 60 seconds per layer; full: tens of minutes (pgTAP and integration need the local stack) |

Rules for every run: `--local` on every `supabase` call; pgTAP before integration; no `db reset`, no seed, no reseed. The known stale-seed reds are a recorded baseline, not regressions: pgTAP 120 #37, 141 #21, 232 #56, 154 #65; `stories.test.ts`, `feed-query-budget.test.ts`, `isolation.test.ts` (5 cases), `modules.test.ts` (cases 1 and 9). Record a baseline run before the first database plan and compare against it.

---

## Sampling Rate

- **After every task commit:** the one quick command of the touched layer.
- **After every plan wave:** `TURBO_CACHE=local:r pnpm turbo typecheck test --continue --concurrency=4`, plus `bash scripts/supabase.sh test db` once the wave touched SQL (pgTAP before integration), plus `pnpm boundaries` and `bash scripts/check-ui-literals.sh`.
- **Before `/gsd-verify-work`:** full suite green apart from the recorded baseline reds.
- **Max feedback latency:** 120 seconds for a quick command.

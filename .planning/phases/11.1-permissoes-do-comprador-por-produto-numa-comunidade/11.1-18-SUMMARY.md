## Decisions Made

- The order is migrations, API and worker together, web last. The worker has no source change of its own in this phase (`git diff` shows no `apps/worker` file); it ships from the same image build so the two never differ.
- The "links off the defaults" and "open highlights" counts are in the after-migration block, because the flag columns do not exist before the release; the before-block asks whether the columns are already there and sends a project that has them to those counts first.
- Rolling the web back is documented as safe only while every link holds the defaults: once a link is non-default the previous web's strict parsers can refuse `communityPermissions` and `community.actions`.
- The section describes no step that hides or removes a refunded buyer's content (D-887): published content stays where it is.

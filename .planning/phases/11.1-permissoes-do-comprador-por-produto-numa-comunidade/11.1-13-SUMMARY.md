# Phase 11.1 Plan 13: The administrator's highlight screens Summary

**An administrator opens and closes a community highlight to buyers with one switch that persists at once (busy, toast, revert on any refusal), sees the open circles through a neutral "Compradores" pill on the manage list, and no member-facing surface can tell open from closed.**

## Accomplishments

- `HighlightEditSheet` takes an optional `openToBuyers` slot `{ checked, busy, onChange, label, helper, extra }` between "Posição" and "Stories neste destaque"; absent draws nothing, the reduced archived sheet never draws it, an empty highlight still does. The module ships no word.
- `setHighlightOpenToBuyersAction` PATCHes the single field and answers the curator row view; `open_unavailable`, a 403 and a transport failure are closed answers. `HighlightManager` persists at once, shows `busy`, toasts "Destaque aberto/fechado a compradores.", reverts on failure with the shipped generic toast and adds the social-off line from the bootstrap module list.
- `HighlightManageList` rows take an optional finished `badge` on a third line; the host draws the neutral pill only on open rows of an active organization community, and the row's description reads "Aberto a Compradores".
- A byte-identical render of the real member chain and a source scan prove the flag stays on curator reads and the manage view.
- The administrator's Playwright spec is written and registered, listed (6 tests) and never run.

**2. [Rule 2 - Missing critical] The pill's accessible name**
- **Found during:** Task 2
- **Issue:** the manage row's body button carries an `aria-label`, so a pill placed inside it is not read by a screen reader and the "Aberto a compradores" phrase of UI-D-896 would never be announced.
- **Fix:** the badge wrapper gets an id and the button `aria-describedby` it only when a badge exists; the name stays the shipped edit label. Tested in B3 and R1.
- **Committed in:** `f8a46221`.

**3. [Rule 1 - Plan inconsistency] The pill is gated by the switch's visibility fact**
- **Found during:** Task 2
- **Issue:** the plan says an open row shows the pill; an archived community, Início or a member community have no switch and the API reports the flag false there, but a stale `true` on an archived highlight would show a mark with no way to act on it.
- **Fix:** the pill shows only where `highlightOpenSectionVisible` is true, the same fact as the switch.
- **Committed in:** `f8a46221`.

## Postar na comunidade

Settled before asking: product links exist only for organization communities (D-713), so "post" never applies to member communities.

| Option | Description | Selected |
|--------|-------------|----------|
| Só na comunidade (Recomendado) | Page of the community only, for whoever reads it, notifies nobody (as the Phase 10 member post) | ✓ |
| Também no Início | Reaches every member of the tenant, a second moderation rule | |

| Option | Description | Selected |
|--------|-------------|----------|
| Exige (Recomendado) | Needs the `social` module on; without it the buyer reads but does not post | ✓ |
| Não exige | Buyer posts with `social` off; a second publish path, more tests and risk | |

**User's choice:** the recommended option in both.
**Notes:** the reserved SQL clause in `feed_posts_social_insert_gate` has no `social_enabled()`, active or tenant term; the new body must carry them.

## Postar story

| Option | Description | Selected |
|--------|-------------|----------|
| Entra num destaque (Recomendado) | Buyer saves their own story in a highlight of the community; everyone who reads the community sees it; the screen warns (D-716) | ✓ |
| Destaque próprio do comprador | Each buyer creates own highlight in the community; needs a limit | |
| Deixar para depois | Four boxes instead of five, about 7 plans | |

| Option | Description | Selected |
|--------|-------------|----------|
| Só em destaque aberto (Recomendado) | The administrator marks which highlights accept buyer stories (a switch on the highlight) | ✓ |
| Em qualquer destaque | Simplest rule; buyer stories mix with the administrator's curated ones | |
| Um destaque automático | A "Dos membros" highlight per community; a new concept | |

**User's choice:** the recommended option in both.

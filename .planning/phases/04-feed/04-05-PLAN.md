<objective>
MEDIA-04 end to end: a link in a post is unfurled server-side behind an SSRF guard that pins the socket rather than the URL, cached per tenant, and rendered as a bordered preview card — or, when it is pending, refused or metadata-free, as nothing more than the auto-linked URL already in the caption.

Purpose: this is the one outbound-HTTP-to-an-untrusted-host surface in the whole product. Nothing else in the tree does it, so there is no in-repo analog to copy and the guard has to be right the first time. RESEARCH falsified the obvious implementation this session — a `lookup`-only guard blocks `localhost` and walks straight through to `http://127.0.0.1/` — so the connector form is mandatory, not stylistic.
Output: the pure guard module with its deterministic local-fixture test suite, the pg-boss worker job, the per-tenant preview cache, and the resolved-only preview card including the no-iframe provider variant.

**Decision — the unfurl is a worker job, and "at create time" is satisfied by initiating it there.** The roadmap says "unfurled server-side at create time". A synchronous fetch would put an attacker-named remote host's latency inside a Cloud Run request and inside the admin's publish tap, against the established rule that the request validates and enqueues (02-13). The URL is validated and the cache row is created at create time, in the same transaction as the post; the bytes are fetched by the worker. The visible consequence is UI-D-11: no pending card, just the bare link until it resolves.

**Decision — no iframe.** `apps/web/next.config.ts` sets response headers only for the service worker and the manifest; there is no Content-Security-Policy anywhere in the web app. Shipping a third-party frame into a private branded community without one would let the embed navigate the top frame and set cookies inside the tenant's origin, and would hand Phase 8 a CSP that must already allow it. YouTube and Vimeo get the same card with a thumbnail and a play badge, opening externally. Inline playback is a Phase 8 item behind a real CSP.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin caption → outbound fetch | an attacker-influenceable URL leaves the worker's network namespace; this is the only such surface in the product |
| remote page → the worker's memory | untrusted bytes of unbounded size and arbitrary encoding |
| remote metadata → a tenant's rendered page | untrusted strings become card text and an external link target |
| job payload → the database | `tenantId` arrives as data and must not be treated as authority |
| tenant A's cache → tenant B | a shared cache would leak what another organisation shared |

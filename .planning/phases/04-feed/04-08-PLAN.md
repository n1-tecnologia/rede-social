## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a shared link → anyone who receives it | the URL itself is not a capability; opening it still requires a session whose membership belongs to that tenant |
| alias host → the shared URL's origin | the primary host is the only correct origin; an alias must never reach a link that leaves the app |
| a miss → what the viewer learns | unknown, foreign and removed must be indistinguishable |

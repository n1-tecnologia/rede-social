## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 5.0.0 (unit per package, API integration on the local stack), pgTAP via `supabase test db`, Playwright 1.63.0 |
| **Config file** | per-package `vitest.config.ts` (`packages/core`, `packages/contracts`, `packages/modules/events`, `packages/modules/payments`, `apps/api`, `apps/web`); `apps/web/playwright.config.ts`; `supabase/tests/*.sql` (each needs `000-helpers.sql`) |
| **Quick run command** | `pnpm --filter @rede-social/core test && pnpm --filter @rede-social/contracts test && pnpm --filter @rede-social/module-events test && pnpm --filter @rede-social/module-payments test && pnpm --filter @rede-social/api test` |
| **Full suite command** | `pnpm db:generate 2>&1 \| grep -q "No schema changes" && pnpm db:reset && pnpm db:seed && pnpm supabase test db`, then `VIDEO_PROVIDER=fake pnpm --filter @rede-social/api exec vitest run tests/integration/<file>.test.ts` per touched file; `pnpm boundaries && pnpm boundaries:negative && pnpm guard:lanes && pnpm guard:hooks`; exit gate `TURBO_CACHE=local:r VIDEO_PROVIDER=fake pnpm verify` (and `--concurrency=4` on turbo runs) |
| **Estimated runtime** | quick ~2-4 min; full suite ~25-40 min (stack up) |

Cautions carried from earlier phases: `pnpm db:reset` only on Igor's word (the local database holds his account); pgTAP **before** integration; `test:integration -- x` does not filter, name the file; clear `apps/web/.next/cache` and `.turbo/cache` between gates (disk is at 90%).

## Sampling Rate

- **After every task commit:** the touched package's Vitest, its typecheck and lint; `pnpm boundaries` when an import changed; the single pgTAP file for SQL-only tasks; the API unit suite whenever a route is mounted (it holds both inventories).
- **After every plan wave:** `pnpm db:generate` prints "No schema changes", then `pnpm db:reset && pnpm db:seed && pnpm supabase test db` (pgTAP **before** integration), then the plan's integration files, then the web unit suites for web plans, then `move-copy.test.ts` once after the schema plan.
- **Before `/gsd-verify-work`:** `TURBO_CACHE=local:r VIDEO_PROVIDER=fake pnpm verify`; `next build` once (only it catches contracts-index `node:fs` leaks); the new `events-tickets.spec.ts` and the three `payments-*.spec.ts` green on `mobile-chromium`.
- **Max feedback latency:** ~240 seconds for a task commit.

# Phase 10.1 Plan 04: The SQL definers of a paid event Summary

**Eleven security-definer functions in `app`: the gateway pair that confirms a presence on an approved purchase and frees or flags it on a refund (service role, outcomes returned never raised), the admin's courtesy / lock / reset / holders definers (admin claim checked inside), and four tenant-pinned reads, all proved in pgTAP 233 sections 4 to 6 with cross-tenant negatives in both directions.**

## Accomplishments

- Task 1 (tracer, failing test first: section 4 ran red with `function app.event_gateway_grant ... does not exist`). `20261113005835_event_gateway_grant_revoke.sql` holds `app.event_gateway_grant(p_tenant, p_membership, p_event, p_provider, p_order_ref, p_admin_release default false)` returning `(outcome, user_id, event_title, over_limit)` and `app.event_gateway_revoke(p_tenant, p_provider, p_order_ref)` returning `(outcome, user_id, event_id)`. The grant validates arguments like the store definer, pins the membership to the tenant, returns `unconfirmed` unless the admin's manual release passes the sixth argument (D-759), takes the per-event advisory lock, re-reads the mapping under it, reads the event `for share` and returns `event_cancelled` / `event_ended` itself, then writes once (insert, not_going to going, or an origin/order upgrade that leaves the status alone). The revoke deletes a not-yet-checked-in row and stamps `refunded_at` on a checked-in one, finds the row by order reference alone with no status or `deleted_at` filter.
- Task 2: `20261113010200_event_courtesy_definers.sql` holds `event_courtesy_grant`, `event_courtesy_remove`, `event_ticket_lock` (same advisory key as the grant, `sold` = tickets only), `event_ticket_reset` and `event_ticket_holders` (at most 50 ids). Each checks the `admin_tenant` claim inside and pins every statement to `app.tenant_id()`.
- Task 3: `20261113010607_event_ticket_reads.sql` holds `event_is_paid`, `event_checkout_url` (gateway open and `https:` only), `event_ticket_admin` (admin claim, answers with the module off) and `event_title_for` (service role only). Section 6 covers the EP-07 matrix, the member-cannot-select assertion, a defence-in-depth case with the table CHECK lifted for one case (an `http:` and a `javascript:` link are never returned), the cross-tenant block and the catalogue matrix.

## Entrar sem pagar

| Option | Description | Selected |
|--------|-------------|----------|
| Não, só quem tem presença | Online `Entrar` and the venue code work only for payers or members released by the admin | ✓ |
| Sim, mas marcado "Sem ingresso" | Everyone enters as today; the admin list marks walk-ins | |
| Só o online fecha | Online link only for payers; in person the admin decides at the door | |

**User's choice:** Não, só quem tem presença (recommended)
**Notes:** The scout showed that `app.events_enter` and `app.events_check_in` record a walk-in for any member inside the window, which would bypass payment.

| Option | Description | Selected |
|--------|-------------|----------|
| Sim, na lista de participantes | `Liberar presença`, marked `Cortesia`, in the pattern of `Liberar manualmente` | ✓ |
| Não, tudo passa pela Kiwify | Guests buy with a 100% coupon created at the gateway | |

**User's choice:** Sim, na lista de participantes (recommended)

## Compra fora do normal

|--------|-------------|----------|

**User's choice:** Fica como "sem conta" (recommended)

|----------|-------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-10.1-24 | Spoofing | a `javascript:` or `http:` link saved as the purchase link | high | mitigate | the form refuses non-`https:` links, the action re-parses with `eventMappingBodySchema`, and the API refuses it; tests for all three |
| T-10.1-17 | Tampering | untrusted text (event title, tenant name) rendered as markup in the section | medium | mitigate | every value is a React text node or a catalog placeholder; no raw HTML |
| T-10.1-02 | Tampering | a product id already used by another event or tenant | high | mitigate | the API answers `gateway_product_taken`; the form shows it under the id field without echoing who owns it |
| T-10.1-30 | Information disclosure | the gateway brand or a token reaching the admin page | medium | mitigate | `{gateway}` is filled from the server's display name list and the neutrality walk runs in the verify |
</threat_model>

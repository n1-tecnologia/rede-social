## Shared Patterns

### Definers, not table writes, across modules (MOD-02)
**Source:** `store_gateway_functions.sql` + `apply.ts` calling `app.store_gateway_*`. The kernel never imports `module-events`; `applyTicket` calls `app.event_gateway_grant(tenant, membership, event, provider, ref, ...)` by SQL name, service_role only.

### Tenant pinning
Every definer statement `tenant_id = p_tenant` (webhook) or `app.tenant_id()` (member lane); apply mapping select pinned `tenant_id = ev.tenant_id` (apply.ts:366-371) (PAY-29).

### Errors
API: `ApiError(404,'NOT_FOUND')` for unknown/foreign ids; `ApiError(409,'CONFLICT',{ payments: '<code>' })`. DB guard: SQLSTATE 23514 with `constraint = 'event_attendances_<x>'` and a short message, mapped by the events service (`guardIssue`, `fullEventAnswer`). Webhook path: outcomes returned, never raised.

### Gateway neutrality
No brand name outside the adapter; `{gateway}` placeholder in copy (`packages/core/tests/payments-neutral.test.ts`).

### Expand-only release
Generated SQL (drizzle-kit) + hand `--custom` SQL; migrations to every tenant database before API; response keys `.optional()`.

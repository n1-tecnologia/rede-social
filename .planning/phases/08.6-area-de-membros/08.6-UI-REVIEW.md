## Top 3 Priority Fixes

1. **Spacing values the contract bans** (WARNING) — the contract says "No 08.6 markup writes a `*-0.5`, `*-1.5`…". This breaks the 4px rhythm the sketch was checked against. Fix: `HomeLive.tsx:86` change `mt-0.5` to `mt-1`; `HomeShelf.tsx:53` change `gap-0.5` to `gap-1`; `MemberTracksTab.tsx:57` change `ml-1.5` to `ml-2` (or centre the 28px disc in a `w-10` column, as TrackTimeline does).
2. **Skeleton height `h-[82px]` is not a multiple of 4** (WARNING), at `MemberTracksTab.tsx:58`. The skeleton jumps when the step cards (`min-h-24`) stream in. Fix: use `min-h-24` / `h-24` so it matches the real step card. Also change `MemberProgressTab.tsx:62` `h-[88px] w-[88px]` to `size-22` (88px is a declared geometric size).
3. **The focus-ring constant is copied into 8 files** (WARNING): HomeShelf, HomeTrack, HomeNewLessons, HomeCategories, HomeLive, TrackTimeline, MemberTracksTab, MemberProgressTab, and LiveCard as well. A single token edit has to touch 9 files, and the copies will drift. This repeats the problem quick 261016-eg6 fixed for buttons. Fix: export a `focusRing` class string from `@rede-social/ui` next to `buttonClasses`/`hitArea` and import it everywhere. In the same pass, swap the "Ver tudo" `-my-3 min-h-11` hack (`HomeShelf.tsx:53`) for the shared `hitArea`.

## Detailed Findings

### Pillar 1: Copywriting (4/4)
- A grep for literal JSX text (`>Word<`) and literal `aria-label="..."` in the 13 member files found 0 hits. All copy comes from `courses.member.*`, `courses.errors.*` and `notifications` catalogues.
- Each error card has its own body key (`courses.errors.home`, `.tracks`, `.progress`) with a shared title and retry. Empty states take the tenant name as an interpolation (`MemberHomeTab.tsx:198-199`, `MemberTracksTab.tsx:202-203`).
- The ReminderToggle accessible name stays fixed ("Lembrete da live {live}") and `aria-pressed` carries the state, as A-UI-9 requires.
- Minor: I did not check the copywriting contract table row by row against the JSON catalogue. UAT test 4 covered the visible strings.

### Pillar 2: Visuals (3/4)
- WARNING: the `FOCUS` string (`focus-visible:ring-2 ring-brand ring-offset-2 ring-offset-bg`) is defined locally in 8 cursos files plus `packages/modules/courses/ui/member/LiveCard.tsx:51`.
- WARNING: `HomeShelf.tsx:53` "Ver tudo" uses `-my-3 min-h-11` to fake a 44px target. Use the shared `hitArea` that 08.5 shipped.
- What is good: 6 files reuse `buttonClasses`/`hitArea` (MemberHomeTab, HomeHero, HomeLive, HomeLiveChoice, MemberTracksTab, MemberProgressTab, ReminderToggle). Each screen has one focal brand fill, as the brand budget table requires.

### Pillar 3: Color (4/4)
- Brand usage in the member files: `bg-brand/10` streak (MemberHomeTab:178) and reminder-on (ReminderToggle:107), `text-brand` Flame/BellRing, `border-2 border-brand` current step (TrackTimeline:15), and `text-brand` "Ver tudo" (item 4). Every other brand use is `ring-brand` focus (item 5) or a ProgressBar fill (P-08.5). That matches the reserved list exactly.
- The zero streak uses `bg-bg-input text-text-tertiary` (not accent), as the spec says.
- 0 hardcoded hex, `rgb()` or `rgba()` values in phase files.
- Note: legacy admin files in the same folder (CoursesTab.tsx:19, LivesTab.tsx:19) still carry local button class strings with `gap-1.5`. This was out of scope for 08.6, but the debt remains.

### Pillar 4: Typography (4/4)
- Sizes: text-xs ×26, text-sm ×11, text-base ×8, text-2xl ×2. Weights: font-bold ×26, font-normal ×22. No `text-[Npx]`, `text-lg`, `font-extrabold` or `font-semibold`. The prototype's sizes were normalised as declared.

### Pillar 5: Spacing (3/4)
- Distribution: mx-4 ×25, gap-3 ×16, mt-1 ×15, px-4 ×14, pb-6 ×14, p-4 ×14, gap-6 ×13, mt-2 ×12. This matches the declared xs/sm/md-s/md/lg scale.
- Violations of the explicit normalisation rule: `HomeLive.tsx:86 mt-0.5`, `HomeShelf.tsx:53 gap-0.5`, `MemberTracksTab.tsx:57 ml-1.5`.
- Arbitrary values: `MemberTracksTab.tsx:58 h-[82px]` (not on the 4px grid) and `MemberProgressTab.tsx:62 h-[88px] w-[88px]` (an allowed geometric size, but written as an arbitrary value).
- Negative margin `-my-3` (HomeShelf:53) is not part of the scale.

### Pillar 6: Experience Design (4/4)
- Início, Trilhas and Progresso each split the result into `disabled` (notFound), `error` (card with retry, frame and row still usable) and empty (`EmptyState`). An empty school falls back to the catalogue empty state.
- Loading: `loading.tsx` plus a per-tab `Suspense` keyed on tab and filter (`page.tsx:145`), with skeletons shaped like the content (ring, step discs).
- ReminderToggle: one pending write at a time, a success toast, and every refusal reverts (`live_locked`/`reminder_closed` refresh, `gone` navigates away). In preview it is disabled and shows the hint (D-422).
- Residual risk: none of this was verified visually because no dev server was running. The only visual evidence is the user's UAT test 4.

Registry audit: no third-party registries in the UI-SPEC (shadcn official only). Skipped.

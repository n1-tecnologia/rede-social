# Phase 08.6 Plan 08: Início lands in the member's hands Summary

**The member's Cursos tab now opens Início. It shows the compact underline row Início · Cursos · Lives, "Bem-vindo de volta." with the server's study streak as a static badge, and the hero card that starts or resumes a course, all rendered from one strict-parsed `GET /v1/courses/learn/overview` inside one `Suspense`. An empty school shows the shipped empty card, and a failed read shows a retry card. Every link that meant "the catalogue" moved to `?aba=cursos`.**

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical] `MemberLessonThumb` gains `sizes` (default `'80px'`)**
- **Found during:** Task 1
- **Issue:** The thumb hard-coded `sizes="80px"`. The full-width hero would have asked the browser for the smallest srcset candidate, so the cover would render blurry.
- **Fix:** An optional `sizes` prop. The default keeps 08.5 rows identical. The hero passes `(min-width: 680px) 648px, 100vw`.
- **Files modified:** `packages/modules/courses/ui/member/MemberLessonThumb.tsx`
- **Verification:** `member-cards.test.tsx` case 2. The module suite passes 326/326.
- **Committed in:** `9c0b7d46`

**2. [Rule 1 - Bug] The hero eyebrow placeholders are named `{moduleNn}` / `{lessonNn}`**
- **Found during:** Task 1
- **Issue:** The Copywriting Contract writes "{course} · Módulo {nn} · Aula {nn}". One ICU message cannot fill two different numbers under one argument name.
- **Fix:** The key is `"{course} · Módulo {moduleNn} · Aula {lessonNn}"`. The visible copy is unchanged.
- **Files modified:** `apps/web/messages/pt-BR/courses.member.json`, `apps/web/lib/courses-member-view.ts`
- **Verification:** The `homeHeroView` cases ("Módulo 02 · Aula 03") and the e2e eyebrow assertion.
- **Committed in:** `9c0b7d46`

**3. [Rule 2 - Missing critical] Streak badge accessible name through `role="img"`**
- **Found during:** Task 1
- **Issue:** UI-D-448 asks for an `aria-label` on a static `<span>`. ARIA does not allow `aria-label` on a generic element, so screen readers may ignore it.
- **Fix:** `role="img"` with the `aria-label`. The `Flame` and the visible label are `aria-hidden`. The badge is still not interactive.
- **Files modified:** `apps/web/app/(app)/cursos/MemberHomeTab.tsx`
- **Verification:** Biome a11y lint is clean, and the e2e checks `aria-label` for "Sem sequência de estudo" and "Sequência de estudo: 1 dia".
- **Committed in:** `9c0b7d46`

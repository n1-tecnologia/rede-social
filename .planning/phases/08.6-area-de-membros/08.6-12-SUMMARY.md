# Phase 08.6 Plan 12: The school's notices in the bell and "Reativar live" Summary

**The bell now renders the six courses kinds with their own glyphs, catalog sentences and deep links. Retracted course notices show the shipped "removed" row. The admin live form offers a brand-confirmed "Reativar live" while a cancelled live's start is still ahead (the database clock decides), and the cancel dialog now says who gets notified.**

## Accomplishments

- **Bell rows (UI-D-460, COURSE-48).** Six renderers keyed by `COURSES_NOTIFICATION_KINDS`:
  - The admin's own actions show the admin's avatar with a kind disc. "Course published" uses `GraduationCap`. "Live scheduled" uses `Radio` and reads "reativou" when the facts carry `reactivated: true`.
  - System events are actor-less glyph rows: lessons added (`BookOpen`, ICU plural), reminder (`BellRing`), cancelled (`CalendarX2`) and replay (`CirclePlay`).
  - `{when}` and `{time}` are shown in the tenant's timezone, computed from the request's single instant.
  - Course rows link to `/cursos/{courseId}` and live rows to `/cursos/lives/{liveId}`. A missing or non-string id links to `/cursos` (EP-64).
- **Glyphs.** `GLYPHS` gains the six icons. The notifications module still imports nothing from courses: boundaries are clean and `grep module-courses` finds 0 matches.
- **Retraction (D-454).** A course notice carrying `{ removed: true }` renders "Este conteúdo foi removido." as a button with no href.
- **Reactivation (D-452, UI-D-462, COURSE-43).**
  - New code: `getLiveReactivation` and `reactivateLive` in `lib/courses.ts`, and `reactivateLiveAction` in `live-actions.ts`.
  - The admin page reads the verdict only when the live is cancelled. `LiveForm` then shows either the note plus the outline full-width "Reativar live", or the past-start note alone.
  - The brand `ConfirmDialog` uses the UI-D-462 copy. Success shows "Live reativada." and refreshes into the editable form with the server's new status.
  - A 409 shows "Não é possível reativar uma live que já começou." and refreshes. Any other failure shows the generic reactivate toast and leaves the form as it was.
- **Cancel dialog (D-447).** Only `courses.live.cancelDialog.body` was reworded. No other catalog value changed.

## Sampling Rate

- **After every task commit:** Run the touched package's quick run (module-courses, api unit, or the web unit set `pnpm --filter @rede-social/web exec vitest run lib/courses-member-view lib/notifications-view i18n "app/(app)/cursos" && pnpm --filter @rede-social/web typecheck && pnpm --filter @rede-social/web lint && bash scripts/check-ui-literals.sh`); plus `pnpm boundaries` when imports change; plus `pnpm db:reset && pnpm db:seed && pnpm supabase test db` when a migration, policy or function changed; plus the drift check `pnpm db:generate 2>&1 | grep -q "No schema changes"` after any schema edit.
- **After every plan wave:** `pnpm db:reset && pnpm db:seed && pnpm supabase test db`, then the touched integration files one at a time with `VIDEO_PROVIDER=fake pnpm --filter @rede-social/api exec vitest run tests/integration/<file>.test.ts` (pgTAP BEFORE integration; `test:integration -- x` does not filter), then the `phase 08.6 sweep`.
- **Before `/gsd-verify-work`:** Full suite plus e2e (`pnpm db:reset && pnpm db:seed && VIDEO_PROVIDER=fake pnpm --filter @rede-social/web exec playwright test courses-member.spec.ts courses-member-area.spec.ts courses-admin.spec.ts`) must be green, with `pnpm db:generate` clean.
- **Max feedback latency:** 120 seconds (per-task quick run)

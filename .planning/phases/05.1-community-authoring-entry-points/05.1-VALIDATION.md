**Video-provider rule (hard):** no validation command may depend on real Mux or a tunnel.
- Vitest (API): an exported `VIDEO_PROVIDER=fake` is not enough today — Wave 0 pins `VIDEO_PROVIDER: 'fake'` as the last `test.env` entry in `apps/api/vitest.config.ts`.
- Playwright: prefix `VIDEO_PROVIDER=fake` and make sure nothing is listening on 8787 (`curl -s -o /dev/null -w '%{http_code}' http://localhost:8787/v1/health` → `000`), otherwise `reuseExistingServer` reuses the developer's Mux-configured API.
- New 05.1 e2e flows publish **image** stories only (`e2e/fixtures/post-a.jpg`).

- **After every task commit:** Run the quick run command

- **Before `/gsd-verify-work`:** Full suite must be green (after the reset+seed checkpoint), then a manual phone UAT
- **Max feedback latency:** 10 seconds (quick tier)

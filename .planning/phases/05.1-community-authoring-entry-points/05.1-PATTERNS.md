## Shared Patterns

### Authorisation by composed permission
Source: `requirePermission('...')` literals in `communities/server/routes.ts:93,128`, `stories/server/routes.ts:155-179,348-392`; web reads `bootstrap.permissions.includes(COMMUNITY_PERMISSIONS.manage | STORY_PERMISSIONS.publish)`. Handler-conditional checks use `permissionsForRequest(ctx)` from `@tria/core/server/rbac/permissions` + `ApiError(403, 'FORBIDDEN')`.

### Refusal shapes
Bare `ApiError(404, 'NOT_FOUND')` for unknown/foreign; `ApiError(400, 'VALIDATION_FAILED', { pin: 'archived' })` for archived target (`stories/server/service.ts:933,975-977`).

### Events after commit (MOD-03)
`emit(ctx, 'story.pinned', {...})` outside `withTenantTx`, only on `inserted.length > 0` (`stories/server/service.ts:994-1001`).

### Server actions
`safeParse` input → try `apiFetch`-backed lib call → catch `ApiClientError` → `bootstrapRedirectPath` → `redirect` outside try; `revalidatePath` on success (`comunidades/actions.ts:50-87`, `story-actions.ts:53-67`).

### Entry points are links
`<a>` styled with brand tokens (`CommunitiesList.tsx:151-160`, `[communityId]/page.tsx:204-215`, `own.href`). Never `Button`/`IconButton` for navigation.

### UI strings
Only from `apps/web/messages/pt-BR/*.json` via `getTranslations`/`useTranslations`; `scripts/check-ui-literals.sh` rejects pt-BR diacritics in JSX and hex colours.

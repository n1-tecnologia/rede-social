# Phase 05.1 Plan 04: The story composer asks where the story goes Summary

**`/stories/publicar` now shows a server-resolved "Publicar em" row above the caption. The row opens the shipped community sheet, whose leading "Nenhuma comunidade" row is the same component the post composer uses. Publishing sends `communityId` only when a community is chosen and lands on that community. If the community is archived while the admin composes, the composer resets the row and says so.**

## Accomplishments
- ROADMAP criteria 3 and 5 now use one mechanism. `/stories/publicar?comunidade={id}` arrives with the "Publicar em" row pre-filled, resolved on the server against the tenant's active communities. An unknown, foreign or archived id falls back to "Nenhuma comunidade" without an error. The row and the pre-fill exist only for viewers who hold `stories.story.publish` and `stories.story.manage`.
- One write per publish (D-99). `communityId` is spread in only when a community is chosen, so a tenant-wide story's body is still exactly `{ mediaAssetId, mediaKind, caption }`. The composer route never references the pin action.
- The landing, the toast and the refusal all name the destination. Publishing lands on `/comunidades/{id}` or `/inicio`, and close or discard returns to the origin. The toast reads "Story publicado em {community}." when the story was attached. An archived community resets the row, is named in the alert and leaves the sheet for this session.
- `PickerDefaultRow` is extracted from `/criar`'s picker (UI-D-55), so the two sheets cannot drift. The web now reads `details.pin` and tells `archived` apart from a generic failure. `publishStoryAction` also revalidates the community page.

## Decisions Made
- The row renders when the **original** `communities` prop is non-empty, not when the refused-filtered list is. If the only community is refused as archived, the row stays and reads "Nenhuma comunidade", so the reset is visible (UI-D-58).
- The row's text and the request's `communityId` come from one derived value (`chosen`). A selection the admin cannot see can never be sent.
- The page keeps only `status === 'active'` communities from `listAllCommunities()`, as `/stories/meus` does.
- An explicit `{' '}` between the label and the value gives the accessible name "Publicar em X". Whitespace between flex items does not render.
- Planning decisions 1-4 applied as written.

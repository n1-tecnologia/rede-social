# Phase 05.1 Plan 02: Archived community list (API) Summary

**`GET /v1/communities?status=archived` now serves managers the tenant's archived communities, most recently archived first, with a microsecond-exact keyset cursor. Members who ask are refused 403, and the default active list runs the same statement as before.**

## Performance

- **Duration:** 9 min
- **Started:** 2026-09-25T13:28:14Z
- **Completed:** 2026-09-25T13:37:14Z
- **Tasks:** 2
- **Files modified:** 6

## Accomplishments
- The contract has a new closed `status` filter: `z.enum(COMMUNITY_STATUSES).default('active')`. An absent value means today's list. `ARCHIVED` and `deleted` get a 400. No response field was added, so `communitySummarySchema` and `communityPageSchema` are unchanged.
- The list handler checks `permissionsForRequest(ctx)` for the literal `'communities.community.manage'`, and only when `status === 'archived'`. The list route has no middleware, so every member can still list. The OpenAPI doc now lists the 400 and 403 responses.
- `listCommunities` picks one of two complete literal statements in TypeScript, and `status` is never bound as a SQL parameter. The active statement is today's, verbatim. The archived statement orders by `updated_at desc, id desc`, and its cursor comes from `cursor_at`: `updated_at` formatted to microseconds in SQL, which never reaches the wire.
- `communityProjection` is now a function, `communityProjection(extra)`, following the `storyProjection` precedent. All five existing call sites call it with no argument and get the same column list.
- Tests added: integration cases 34-41, an archived-list budget case (ceiling plus floor, with a non-empty page and a hydrated cover), and pgTAP case 16b (`plan(59)`).

## Decisions Made
- **D-89 goes to the API as a refusal.** A member sending `status=archived` gets `403 FORBIDDEN`, the same answer `requirePermission` gives everywhere else, and case 34 pins it with the admin's 200 as the control in the same test. Coercing a shared `?status=arquivadas` link back to the active list is the web tier's job (05.1-03).
- **`status` does not clamp.** An unknown or differently-cased value can only come from a crafted call, so it gets an explicit 400. `limit` clamps because a navigation tab can send it; `status` has no such caller.
- **No index for the archived branch (D-91).** The budget case proves the read is one statement. `pnpm db:generate` reported "No schema changes, nothing to migrate".

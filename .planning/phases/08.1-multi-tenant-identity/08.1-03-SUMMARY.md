# Phase 08.1 Plan 03: Generic-Host Community Picker Summary

**On localhost or Vercel Preview, an identity in several communities now picks one on `/escolher-comunidade`. The choice is stored in the HttpOnly `tenant_slug` cookie and forwarded as `x-tenant-choice` on generic hosts only. The API honours it only among the caller's own memberships, so tenant and platform hosts never list or name another community.**

## Accomplishments

- **API.** `GET /v1/join/communities` runs in the identity lane.
  - `communitiesOf` reuses `membershipsOfUser` and drops blocked rows. That is the selectable set of `pickGenericMembership`, so the picker and `requireAuth` cannot disagree.
  - Order: display name with `localeCompare(…, 'pt-BR')`, then slug.
  - A verified tenant host or `PLATFORM_HOST` gets 404 `NOT_FOUND`.
- **Contracts.** `communitySchema` and `communitiesSchema`, both `.strict()`. They are pinned by contract tests 7 and 8.
- **Cookie and header.**
  - `TENANT_SLUG_COOKIE` and `TENANT_SLUG_MAX_AGE_S` now live in `lib/tenant-host.ts`, and `proxy.ts` imports them. The proxy's behaviour is unchanged.
  - `lib/api.ts` reads the cookie only when `getHostTenant().mode === 'generic'`. It sends the cookie as `x-tenant-choice` from both `authHeaders` and `apiFetchWithToken`.
- **Bootstrap.** `TENANT_CHOICE_REQUIRED` now redirects to `/escolher-comunidade`.
- **Picker (UI-D-322).**
  - On a tenant or platform host the page calls `notFound()` before any fetch.
  - Otherwise it shows the heading, the sub-line, one form per community, the empty state, the `?erro=invalida` alert and a "Sair" form (`declineJoin`, local sign-out).
  - `chooseCommunity` re-reads the list and refuses a slug outside it. Only then does it write the cookie, with the proxy's exact attributes.
- **WINDOWS #75.** `/participar`'s `join` now signs out locally on `MEMBERSHIP_BLOCKED` and `TENANT_SUSPENDED` before it redirects. The ledger entry and the deferred item are closed.
- **Tests.**
  - `join.test.ts`: n1-n4.
  - The isolation sweep now also checks the list on a generic host and the 404 on the lab host.
  - e2e: the tracer, five edge cases and the #75 case, run on both projects.
  - `participar/actions.test.ts` (8 cases).

## Decisions Made

- **One loader for the page and the action.** The list the page renders and the list `chooseCommunity` checks come from the same `load.ts`. The file has no `'use server'`, so the browser cannot call it as an action.
- **Plain buttons in the picker.** They have the secondary look and `min-h-11` instead of `SubmitButton`'s fixed height, so a long community name wraps.
- **`/participar` refusals.** Suspended now goes to `/auth/suspended`; it used to fall through to `?erro=falha`. Blocked and suspended both sign out locally first. `FORBIDDEN` keeps the session, because the refused card has its own "Sair".

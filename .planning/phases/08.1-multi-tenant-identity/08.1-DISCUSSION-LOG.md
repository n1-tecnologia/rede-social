## Fluxo de "já tem conta"

| Option | Description | Selected |
|--------|-------------|----------|
| Pede a senha na mesma tela | Form becomes "Você já tem uma conta. Digite sua senha para participar de [B]"; password + consents create the membership | ✓ |
| Manda para /entrar de B | "Já tem conta, entre", then a "Participar de [B]" screen after login | |
| Confirmação por e-mail | A link in the e-mail creates the membership, no password | |

| Option | Description | Selected |
|--------|-------------|----------|
| Pode revelar "já tem conta" | Says the e-mail has an account on the platform, never which community (D-04) | ✓ |
| Não revelar nada | Always "enviamos um e-mail para continuar"; forces e-mail confirmation | |

| Option | Description | Selected |
|--------|-------------|----------|
| Link "Esqueci a senha" com a marca de B | Normal recovery started on B's host; back to B's sign-up afterwards | ✓ |
| Redefinir já cria a membership | Reset on B's host enters B directly, consents on first screen | |

| Option | Description | Selected |
|--------|-------------|----------|
| Sim, bloqueio é só de A | Each community moderates its own; B never learns | ✓ |
| Sim, mas o bloqueio em B impede voltar | Same plus explicit no re-registration in B | |

**User's choice:** all recommended options.
**Notes:** the second blocking option is implied anyway: an existing `blocked` B membership stops re-joining B (recorded in D-304).

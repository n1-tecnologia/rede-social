# Phase 08.1 Plan 05: Auth mails branded by the flow's host Summary

**Every auth e-mail is now branded by the community whose verified host the flow started on: a pure nine-row `decideMailTenant` table over an uncached `tenant_domains` read. Recovery is branded by that host even for someone who is not a member yet (D-317), so "forgot my password while joining rede-lab" ends on rede-lab's join screen. The reset screen carries the shared-password notice.**

## Accomplishments
- `decideMailTenant` implements D-315/D-317 rows 1-9. `resolveMailTenant` only gathers the facts: H uncached, `membershipInTenant`, an open invite FOR H, `membershipsOfUser` and an open invite anywhere. No path brands a mail by "the oldest membership" or "the newest invite" any more.

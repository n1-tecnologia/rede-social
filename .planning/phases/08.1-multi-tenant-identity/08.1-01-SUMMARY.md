## Accomplishments

- **Reconcile record.** `08.1-RECONCILE.md` lists every hit of the nine grep groups. Each hit has a disposition: 84 move, 7 are new sites, 220 need no change. It also checks the Phase 8 decisions against D-304, D-309 and D-310. Phase 8 blocks and role changes are `(id, tenant_id)`-scoped and every sign-out is local, so there is no blocking conflict. The `For 08.1-07` list names the new tenant-lane routes and migrations.
- **Expand migrations.**
  - The generated migration is the single `DROP INDEX "memberships_one_tenant_per_user_v1"`.
  - The custom migration adds `app.membership_in_tenant(uuid, uuid)` and `app.memberships_of_user(uuid)`: SECURITY DEFINER, `search_path = ''`, no `limit`, executable by `api_user` only.
  - `app.membership_for_user` is untouched for the deploy window.
- **`requireAuth` is host-first (D-307).** On a tenant host it reads only the host tenant's membership. No row there means 403 `TENANT_HOST_MISMATCH` with no details. Block, suspension and role are read from that membership alone (D-304).
- **Generic hosts (D-308).** On any other host, `requireAuth` applies the pure `pickGenericMembership` to the caller's memberships. The new `x-tenant-choice` header only picks among the caller's own memberships, and the answers are `NO_MEMBERSHIP`, `TENANT_CHOICE_REQUIRED` or `MEMBERSHIP_BLOCKED`, all without details. The platform-admin branch moved off the hot path into `GET /v1/join/state`.
- **Identity lane.** `requireIdentity` sets `c.var.identity` and never sets `ctx`. It is mounted only on `/v1/join`.
  - `joinState` answers one of seven states, and only about the host's tenant.
  - `joinTenant` runs one `withAdminTx`. It refuses a suspended tenant, a platform account (D-316), stale consents, a soft-deleted membership, a block (D-304) and an invite still pending (D-29). Otherwise it inserts with `on conflict do nothing`, sets the typed profile name (D-311) and writes both consent rows.
- **Web.**
  - `TENANT_HOST_MISMATCH` now routes to `/participar`, built per UI-D-320 from the `(auth)` primitives. The decline is a local-scope sign-out.
  - A 404 from an old API (web deployed before the API) still goes to `/auth/host-mismatch`.
  - `join.json` holds every string.
- **Tests.**

  - `join.test.ts`: the tracer plus the guard matrix, cases a-l.

## Decisions Made

- **Precondition (developer decision, 2026-10-06).** 08.1 runs before Phase 8 closes. The precondition loop printed exactly `missing …/08-12-PLAN.md`, the accepted state. 08-12 is paused at its go-live checkpoint and touches no source code 08.1 reads. This is recorded in `08.1-RECONCILE.md`.
- **Join checks a removed row first.** `joinTenant` checks a soft-deleted row before blocked, invited and active. A removed member with `status = 'active'` must get 403 `FORBIDDEN`, never `already_member`.
- **Tenant status comes from the row.** `joinState` reads the tenant status from `tenants`, not from the 60 s host cache.
- **Join routes get a real isolation case.** The isolation-inventory gate only allows exemptions for the public, platform, hook and webhook route families. So `/v1/join` got a real cross-tenant case in `isolation.test.ts` (`08.1 join sweep`, no writes) instead of an exemption.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 5.0.0 (api, core, contracts, web units); pgTAP via `supabase test db`; Playwright 1.63.0 |
| **Config file** | `apps/api/vitest.config.ts`, `packages/core/vitest.config.ts`, `apps/web/playwright.config.ts` |

| **Full suite command** | `pnpm db:generate && test -z "$(git status --porcelain -- supabase/migrations)" && pnpm db:reset && pnpm db:seed && pnpm supabase test db && pnpm --filter @rede-social/api exec vitest run tests/integration/isolation.test.ts tests/integration/auth-middleware.test.ts tests/integration/join.test.ts tests/integration/send-email-hook.test.ts tests/integration/invites.test.ts tests/integration/signup.test.ts tests/integration/bootstrap.test.ts tests/integration/profile.test.ts tests/integration/realtime.test.ts tests/integration/push.test.ts`, then `pnpm --filter @rede-social/web typecheck && pnpm --filter @rede-social/web lint && bash scripts/check-ui-literals.sh && VIDEO_PROVIDER=fake pnpm --filter @rede-social/web exec playwright test multi-tenant-identity.spec.ts signup.spec.ts host-mismatch.spec.ts invite.spec.ts recovery.spec.ts` and `pnpm boundaries` |
| **Estimated runtime** | ~600 seconds (full); ~90 seconds (quick) |

`pnpm test:integration -- x` does not filter; always use `pnpm --filter @rede-social/api exec vitest run <files>`.

## Sampling Rate

- **After every task commit:** Run the quick run command
- **After every plan wave:** Run the full suite command, sequentially (never while another session uses the local Supabase stack)
- **Before `/gsd-verify-work`:** Full suite green, plus the whole `apps/api/tests/integration` directory and `pnpm e2e` (full two-tenant isolation gate with the shared-identity fixture)
- **Max feedback latency:** 600 seconds

# Phase 09.2 Plan 19: The Banco tab Summary

**The sixth tenant tab answers an operator's three questions in order: the overview card says whether the database is up (one pill vocabulary for the eight states, a notice row per state), what it is (project with a dashboard link built only from a 20-letter ref, schema, plan, sharing) and lets them check now; the Preparação card shows the eight bootstrap steps in a fixed order, resumes at the failed one with a single request, refreshes itself while the run is in progress and folds into one line when done; the Credenciais card says access is held and replaces it through a write-only sheet that the server validates against the project first**

## Accomplishments

- **Tracer (UI-D-536, UI-D-539, DBT-51/24/27).** `TENANT_KEYS` gained `banco` between Admins and Status; `/plataforma/tenants/{id}/banco` reads the detail through `requirePlatformTenantDetail` and the database through `requirePlatformTenantDatabase` (401/403 navigate, anything else reaches `error.tsx` while the frame and the six tabs stay). `DatabasePill` is the single table of the eight states (Pronto success; Em preparação, Em mudança, Não verificado neutral; Atrasado, Pausado warning; Preparação falhou, Inacessível danger). The overview card follows the sketch: pill and "Verificado há 3 min.", the `dl` with `minmax(0, …)` columns, the ref `break-all tabular-nums`, the Supabase link only for `^[a-z]{20}$`, the notice row by state with "Código {code}" inside it.
- **Preparação (UI-D-537, D-542).** The eight steps always render in `BOOTSTRAP_STEP_KEYS` order; waiting `Circle`, running spinning `Loader2`, done `CircleCheck` brand, failed `XCircle` with the catalog sentence of the reason code and "Código {code}", each with a visually hidden status word. "Tentar de novo" is `loading`, guarded by a ref and swallows the 409; the card refreshes every 3 s while the run is in progress (probe first), stops when it ends or fails, and collapses to "Preparação concluída em {data}." with a closed native `<details>` "Ver etapas".
- **Credenciais (UI-D-538, D-539, DBT-40).** Lock + the sentence (or the missing note), the Guardadas/Não informadas pill, "Atualizadas {when}." and the outline "Substituir credenciais". The sheet reuses `ProjectAccessFields requireAll={false}`, opens empty, locks while saving, keeps itself open on a refusal ("Nada foi alterado.") with the typed values, and on success closes, toasts and refreshes. The server action validates the body with the API's own Zod, sends it once and answers a flag or a catalog key.

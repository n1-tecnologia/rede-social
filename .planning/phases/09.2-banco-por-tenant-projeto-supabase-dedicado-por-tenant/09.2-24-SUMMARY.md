## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical] The migrate Job lacked the sender domain and the SMTP password the move's bootstrap needs**
- **Found during:** Task 2, writing the move runbook (what a `ROLE=move` execution of the Job reads)
- **Issue:** the move bootstraps its target inline, and the `auth` step reads `MAIL_DOMAIN` (defaults to a local development domain) and `PROJECT_AUTH_SMTP_PASS` (absent means `auth_config_failed`). The Job carried neither, so the documented production move could not complete, and `gcloud run jobs execute` cannot add a secret mount.
- **Fix:** `MAIL_DOMAIN=n1marketingdigital.com.br` in `env_vars` and `PROJECT_AUTH_SMTP_PASS` from `resend-smtp-pass-prod` / `-hml` in the Job's secrets, in both workflows (both already on the services, so the guard's lists hold).
- **Files modified:** .github/workflows/deploy-api.yml, .github/workflows/deploy-hml.yml
- **Verification:** `pnpm guard:workflows` (guard, self-test, release-env self-test) and a YAML parse
- **Committed in:** 57378c58

**2. [Rule 1 - Bug] The migrate Job did not name project 0's own ref**
- **Found during:** Task 2, reading `ensureProjectZero` (the fan-out calls it)
- **Issue:** it writes `SUPABASE_PROJECT_REF`, or the development value `local` when unset, into the central registry row. The services set the ref and the Job did not, so every deploy would have written `local` until the worker boot wrote the real ref back (the panel's dashboard link, the probe and any ref-based lookup would see it).
- **Fix:** `SUPABASE_PROJECT_REF` in the Job's `env_vars` (the same literal as the services in production, the same variable in homolog).
- **Files modified:** .github/workflows/deploy-api.yml, .github/workflows/deploy-hml.yml
- **Verification:** `pnpm guard:workflows`, YAML parse
- **Committed in:** 5d15640e

**3. [Rule 1 - Bug in a comment] The worker header counted 4 pooled sockets per tenant project**
- **Found during:** Task 2, recomputing the budget from `env.ts` (default 3)
- **Issue:** the comment said `PROJECT_POOL_MAX` was 4 and a tenant project cost 7 sockets, and plan 09's SUMMARY and the handoff repeated 4. The code ships 3 (6 sockets).
- **Fix:** the comment says 3 and 6; the DEPLOY.md budget uses 3.

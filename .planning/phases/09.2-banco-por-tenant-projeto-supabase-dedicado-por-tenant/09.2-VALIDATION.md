## Sampling Rate

- **After every task commit:** the single targeted Vitest file(s) (< 30 s) plus `pnpm turbo typecheck` for tasks that change a seam signature (`withTenantTx`, `withAdminTx`, the platform lane, `enqueueInTx`).
- **After every plan wave:** `pnpm turbo typecheck test` + `pnpm supabase test db` + the wave's integration files + `pnpm boundaries:negative && pnpm guard:lanes`.
- **Before `/gsd-verify-work`:** `TURBO_CACHE=local:r VIDEO_PROVIDER=fake pnpm verify` green; hosted proofs H1-H8 recorded in UAT as human-needed, never as a blanket pass.
- **Max feedback latency:** about 120 s for a task's unit sample; integration and e2e samples are per plan.

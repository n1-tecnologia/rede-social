# Phase 09.2 — Edge coverage ledger (spec-less probe fallback, §C)

> Companion to the twenty-eight PLAN.md files. The phase has no SPEC.md, so the orchestrator ran the deterministic edge probe over the researcher's draft DBT-01..DBT-43 texts (84 applicable edges, all `unresolved`). While finalising the requirements ten requirements were added: **DBT-44** (the image carries both migration sets and a manifest), **DBT-45** (the registry binding cache has a bounded stale window and then fails closed), **DBT-46** (a tenant with no binding fails closed), **DBT-47** (break-glass credential reissue), **DBT-48** (a moving tenant cannot be reactivated or edited), **DBT-49** (after the last move the central project holds platform data only), and the four panel and member-screen requirements **DBT-50..DBT-53** (the ref field, the Banco tab, the list column and move guard, the held-out screens). The draft wording of DBT-01..DBT-43 was kept verbatim, so the engine's 84 rows hold, and the rows the ten new requirements produce (P85..P107, appended in the engine's own category vocabulary; P95 and P96 were reserved for DBT-48 and P106 and P107 were added later for DBT-49) are listed after them. Every item has an id (P1..P107), a resolution and the plan whose `must_haves.truths` carries it, so the checker (`scripts/check-phase-plan-coverage.mjs`, plan 28) can confirm the no-silent-drop equality:
>
> **107 = 89 authored as `explicit` truths + 0 `backstop` + 18 flagged assumptions (`unclassified`, never auto-resolved: P14, P15, P23, P24, P31, P36, P44, P53, P58, P60, P61, P70, P71, P72, P73, P75, P77, P84)**.

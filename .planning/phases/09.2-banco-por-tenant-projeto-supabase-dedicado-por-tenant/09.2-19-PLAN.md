<objective>
Build the sixth tenant tab, 'Banco': where an operator sees whether a tenant's database is up, what and where it is, how far it has been prepared, and replaces its access when it changes upstream.

It answers the three questions in the order an operator asks them. The overview card says whether it is up (the pill), what it is (project, schema, plan, sharing) and where it is behind (notice rows). The Preparação card shows the eight steps, resumes at the one that failed and collapses to one line when done. The Credenciais card makes plain that nothing is shown or returned and offers a validated replacement. Everything reads plan 14's API; nothing computes a state of its own (the pill mapping is one file).

Tracer: the tab exists, is reachable, and the overview of a tenant renders from the live API shape with the correct pill and notice. Tasks 2 and 3 add the steps and the credentials.

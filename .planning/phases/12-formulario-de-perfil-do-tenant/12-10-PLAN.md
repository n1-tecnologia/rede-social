## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored member text to a spreadsheet application | names, titles and answers are attacker-controlled text that Excel or Sheets may execute as formulas |
| admin request to a personal-data download | the export is the one door through which all answers leave the app |
| admin lane to tenant data | the e-mail join runs with RLS off, so the explicit tenant predicate is the only isolation |

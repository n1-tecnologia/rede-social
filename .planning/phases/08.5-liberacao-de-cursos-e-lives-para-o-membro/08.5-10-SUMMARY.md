# Phase 08.5 Plan 10: The admin's sequence switch and "Ver como aluno" Summary

**The admin sets "Exige concluir a aula anterior" per lesson. The switch says why before the tap when it is disabled, on the first lesson or while "Aula aberta" is on. The curriculum row reads " · Exige a anterior". The admin can also open any published course "como aluno" from a 44px eye on the hub row or a link above "Despublicar". The preview plays lessons and opens materials, and it writes no progress.**

## Accomplishments

- **Lesson switch (D-428, UI-D-438, A-UI-6).** `LessonForm` shows the switch after "Aula aberta", with three helper states:
  - first lesson: disabled, "Esta é a primeira aula do curso.";
  - free lesson: disabled, off, "Aulas abertas nunca ficam bloqueadas.";
  - otherwise: "Quem não concluiu a aula anterior vê esta aula bloqueada."

  A new lesson starts off. Create sends the effective value. An edit patches `requiresPrevious` only when it changed, and turning "Aula aberta" on sends it `false`. Both lesson pages pass `isFirstLesson` from `isFirstLessonOfCourse`. The edit page now reads the course detail beside the lesson.
- **Captions.** `LessonRow` gains `requiresPreviousLabel`, rendered after the meta as " · " + `Lock` 12 + "Exige a anterior". `lessonRowView` fills it and `CurriculumEditor` passes it on. The module sheet's helper is reworded to "Quem não concluiu o módulo anterior vê este módulo bloqueado. O primeiro módulo nunca fica bloqueado."
- **"Ver como aluno" (D-422, UI-D-437).** A published hub row gets a sibling 44px `Eye` 20 link named "Ver como aluno: {course}", placed after the row link. Drafts and archived rows have none. On the course page, the published action zone gets the outline `fullWidth` link "Ver como aluno" (`Eye` 18) above "Despublicar". Both links go to `/cursos/{id}?ver=aluno`.
- **Browser coverage.** The admin cases cover the switch states, persistence after a reload, the row caption and the reworded module helper. They also check the eye on published rows only, its DOM order and its 44px box, and the course-page link above "Despublicar". A new `describe('preview')` covers:
  - the course-page link to the banner;
  - a lesson that keeps `?ver=aluno`, plays and opens its material, with no completion zone;
  - zero admin progress rows after the visit;
  - no banner for a member or for the support user (support keeps the completion zone);
  - "Nenhuma aula ainda" in preview, as for a member.
- **WINDOWS entry 85 closed.** The create body no longer hard-codes `requiresPrevious: false`.

## Decisions Made

- Planning decisions 1-2 were implemented as written (see `key-decisions`).
- **The switch's effective value.** It is `false` whenever the lesson is first or free. The form also starts from that effective value, the `ModuleSheet` WR-02 rule. A stale stored `true` therefore never opens the form dirty, and it is never re-sent.
- **The caption is dropped on a free lesson.** D-429: an open lesson ignores the sequence. The server never stores the flag there anyway.
- **`lesson-row-meta` still holds only the meta.** The caption is a sibling, `lesson-row-requires`, so existing exact-text meta assertions keep passing.

## Sampling Rate

- **After every task commit:** Run the touched package's quick run; plus `pnpm db:reset && pnpm db:seed && pnpm supabase test db` when a migration/policy/function changed; plus the drift check (`pnpm db:generate && test -z "$(git status --porcelain -- supabase/migrations)"`) after any schema edit.
- **After every plan wave:** `pnpm lint && TURBO_CACHE=local:r pnpm turbo typecheck test`, then `pnpm db:reset && pnpm db:seed && pnpm supabase test db`, then the integration files `courses-learn.test.ts courses.test.ts media-playback.test.ts store.test.ts store-gate.test.ts isolation.test.ts bootstrap.test.ts modules.test.ts` one at a time with `VIDEO_PROVIDER=fake pnpm --filter @rede-social/api exec vitest run tests/integration/<file>.test.ts` (pgTAP BEFORE integration; `test:integration -- x` does not filter).
- **Before `/gsd-verify-work`:** Full suite must be green
- **Max feedback latency:** 120 seconds (per-task quick run)

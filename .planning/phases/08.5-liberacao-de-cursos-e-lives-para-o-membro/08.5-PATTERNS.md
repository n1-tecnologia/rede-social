## Shared Patterns

### Guard chain
**Source:** `packages/modules/courses/server/routes.ts` L83-118.
**Apply to:** all new course and store routes. The order is `requireAuth -> requireModule(...) -> (permission only on admin routes)`. Member `/learn/*` routes carry no `middleware`.

### Gate seam read (mandatory coalesce)
**Source:** `packages/core/db/course-gate.ts` (`LOCKED_COURSE_IDS`, `LOCKED_LIVE_IDS`).
**Apply to:** every service SQL and SQL function. Never write a bare `<> all ((select app.f()))`.

### Definer function hardening
**Source:** `20261008174609_feed_gate_lookups.sql` L30-31: `security definer set search_path = ''`, fully qualified names, `app.tenant_id()` pin, `revoke all ... from public; grant execute ... to authenticated`.
**Apply to:** all new SQL functions.

### Bare 404 for every miss (D-23)
**Source:** `store/server/service.ts` L705 `if (!result) throw new ApiError(404, 'NOT_FOUND');` and `media/service.ts` L846.
**Apply to:** learn routes, store access routes, media gate.

### Catalog strings, no literals
**Source:** `apps/web/messages/pt-BR/courses.json`. The new `courses.member.json` has root `courses` (UI-D-445). `scripts/check-ui-literals.sh` must stay green.

### App-tier composition of store + courses UI
**Source:** `LockedCommunity.tsx` imports store UI in `apps/web`. Courses UI never imports store UI (MOD-02, `pnpm boundaries`).

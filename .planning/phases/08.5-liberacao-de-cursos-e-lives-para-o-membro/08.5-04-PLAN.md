<planning_decisions>
1. **Catalogue order** is `published_at desc, id desc` ("newest published first", UI-D-425); `published_at` is set once on the first publication (`coalesce(published_at, now())`), so a republish does not move a course to the top.
2. **Agenda paging:** the first page carries the whole upcoming group (it is small and nearest-first) plus 20 recorded; only "Gravadas" pages (UI-D-434).
3. **Live page state machine** is computed on the server (`LIVE_PAGE_STATES = ['cancelled','locked','open','before','replay','ended']`), so the web renders one zone without clock math (UI-D-435, UI-D-436).
4. **Join window helper** `liveJoinWindowAt` lives beside `liveStatusAt` in the contracts (pure, unit-tested at the exact boundaries); `LIVE_JOIN_LEAD_MINUTES = 15`.
5. **Replay of a lesson in an unpublished course** keeps playing from the live page while the lesson is live (CONTEXT default), because the access answer's live door does not look at the course status.
</planning_decisions>

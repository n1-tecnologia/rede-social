# Phase 08.5 Plan 09: The Member's Live Page Summary

**Every live now has a member page at `/cursos/lives/[liveId]`. It shows one zone, the one the server decided: when the live starts, the "Entrar na live" link inside the 15-minute window, the replay with its materials, a cancelled or ended notice, or the buy section of a locked live. The page refreshes itself at the window's edges from the server's `serverNow`, never from the browser clock. The join link never reaches a DOM outside the window or for a locked live.**

## Accomplishments

- **Role split** (`lives/[liveId]/page.tsx`). A `courses.manage` holder keeps the shipped live form, unchanged. Everyone else makes one `getLearnLive` read:
  - `ok` gives `MemberLivePage`;
  - `not_found` (unknown, foreign, or a crafted non-uuid id) gives the new segment `not-found.tsx` "Live indisponível" / "Ver as lives";
  - a read failure gives the error card with a retry.
- **Page** (`MemberLivePage`): header "Voltar para Lives", the 16:10 cover (gradient fallback) with the over-media status pill ("Ao vivo agora" with `Radio`) and "Exclusiva", the title 24/700, "quinta, 22 de outubro, 19:00 · 60 min" in the tenant timezone, and the description with "Ler mais".
- **State zone** (`LiveStateZone`). Exactly one zone, from the API's `state`:
  - `cancelled`: `CircleX` and "Esta live foi cancelada.";
  - `locked`: the plan-07 locked markup with `lockedLiveView`;
  - `before`: `CalendarClock`, "Começa em …" or "Começa hoje …", and the hint;
  - `open`: the brand `<a target="_blank" rel="noopener noreferrer">` to the API's `joinUrl` (https only), with the early or on-air helper;
  - `replay`: the "Assistir ao replay" button and "Materiais da gravação";
  - `ended`: the no-recording line.
- **Replay** (`LiveReplay`). The tap swaps the cover box for `LessonPlayer` in a 16:10 box, so there is one playback mint per tap and no layout shift. The player resumes at `lastPositionSeconds`. Writes go through the 15-second reporter and the beacon for the replay lesson. Focus moves to the player box, then to `<mux-player>`, which is asked to `play()`. The materials share the replay lesson's session.
- **Timer** (`useWindowRefresh`). It waits for the next edge (`joinOpensAt`, `startsAt`, `endsAt`) minus `serverNow`, plus 1 s, capped at 24 h. Past the last edge it schedules nothing. It is mounted only for `before` and `open`.
- **Buy section** (`lockedLiveView`, `getLiveAccess`).
  - "Live exclusiva" with the live bodies.
  - Hrefs `/loja/{id}?live={liveId}`, ids encoded.
  - The sheet helper reads "Qualquer um destes produtos libera {live}.".
- **Browser.** `describe('live page')` has 10 cases. On a fresh reset the whole `courses-member.spec.ts` ran 59 passed, 5 skipped, 0 failed in 3.3 min. The 5 skips are the desktop runs of the five phone-only 320px backstops.

## Decisions Made

Planning decisions 1-3 were implemented as written (see `key-decisions`). Choices made during execution:

- **Sketch 010 finding 2 (the "Gravada" pill on an ended live without a recording).** The status pill is dropped in the `ended` state. A pill saying "recorded" over "A gravação não está disponível." contradicts itself, and the zone already says what happened. The reviewer can restore it if the server vocabulary should win.
- **The timer also stops at `startsAt`.** Inside the window, the pill ("Agendada" → "Ao vivo agora") and the helper ("Você já pode entrar" → "A live acontece fora do app…") change at the start. A one-second grace keeps the refreshed read past each half-open edge. `startsAt` is optional in `windowRefreshDelay`, so the plan's signature still holds.
- **Date line.** pt-BR's `Intl` long weekday is "quinta-feira". The contract and sketch write "quinta", so "-feira" is dropped. "sábado" and "domingo" are unaffected.
- **"Começa em" date.** "22 de outubro" (day and month), as the screen contract and sketch draw it. The meta line carries the weekday.
- **An `open` answer without a usable https link** renders the `before` words, so a link is never invented and a `javascript:` URL can never be a link.
- **A replay lesson without a video** shows the no-recording line, and its materials are still listed.
- **Member read failure** uses the shipped `courses.errors.{title,lives,retry}` words. The contract has no live-page error line.
- **Not-found header.** The title is "Lives" (`courses.hub.tabs.lives`), as sketch 010 draws the unknown-live frame.

**2. [Rule 2 - Missing critical] Only an `https:` `joinUrl` becomes a link**
- **Found during:** Task 1
- **Issue:** The API validates https-only at write time (COURSE-11). The page would still render whatever string the answer carried into an `href`.

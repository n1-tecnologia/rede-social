# Phase 05.2 Plan 04: Inicio Tenant Circle and Highlight Circles Summary

It is built from one reworked StoryCircle/StoriesStrip unit that can draw every disc and ring 05.2 needs.**

## Accomplishments

- `StoryCircle` has a `ring` prop (`brand` / `neutral` / `dashed`) that is independent of its `disc` (`asset` / `own` / `logo` / `monogram` / `glyph`). It keeps three shells: an anchor when there is an `href`, a button when there is an `onOpen`, and a span otherwise. The exported `StoryMonogram` takes the first grapheme, so a joined family emoji stays whole. Docblock item 1 now states D-105.
- `StoriesStrip` renders ordered `link` / `open` / `static` descriptors and calls `onOpen(group, index)` with each circle's own pair. An empty list renders no node at all, and the skeleton is unchanged. The D-78 paragraph was rewritten to D-104/D-106.
- Inicio (`storiesHome`) reads `loadStories({ limit: 25 })` and `loadHighlights({})` in one `Promise.all`, reverses the page with `tenantSequence`, and builds the row with `inicioRow`. Members never see the `+` circle or empty highlights.
- The community page's pinned row and the `/inicio` viewer behave exactly as before. They go through the new descriptors, and `StoriesSurface` adapts `(group, index)` to the single-sequence viewer.
- The browser proves the new row on phone and desktop for a member and an admin. The tenant circle opens on the oldest live seeded story (`…d3`) and advances to the next-newer one.

## Decisions Made

- **A third descriptor kind, `static`.** The plan named two kinds, but a highlight circle has to stay inert while the tenant circle in the same row is openable. An `open` descriptor would have become a button that does nothing. `static` renders the shipped span. Plan 05 switches highlight circles to `open`.
- **`inicioRow` as a pure builder.** The UI-D-59 order and render rule are unit-tested (cases 13-17) instead of living only inside the async RSC.
- **`circle.action` kept.** The community page's pinned row still reads it. Plan 08 replaces that row and can remove the key.
- **The backstop fills 25.** With the tenant circle reading `STORY_MAX_PAGE_SIZE`, 25 segments are reachable in the product. The old docblock ("25 is not reachable") would otherwise have contradicted the code.

## Pattern Assignments

### `packages/modules/stories/db/schema.ts` (model)

**Analog:** same file `:152-190`. Copy the table shape verbatim (tenant first, cascade FKs, unique arbiter, `.nullsFirst()` on desc index keys, `tenantIsolationPolicy`, `.enableRLS()`). `community_id` gets **no** `.references()` (MOD-02); the FK is hand-written SQL.
```typescript
export const storyCommunityPins = pgTable(
  'story_community_pins',
  {
    id: uuid().primaryKey().defaultRandom(),
    tenantId: uuid('tenant_id').notNull().references(() => tenants.id, { onDelete: 'cascade' }),
    storyId: uuid('story_id').notNull().references(() => stories.id, { onDelete: 'cascade' }),
    /** -> `public.communities.id` on delete cascade, declared in SQL. See the docblock above. */
    communityId: uuid('community_id').notNull(),
    pinnedByUserId: uuid('pinned_by_user_id').notNull().references(() => users.id),
    pinnedAt: timestamp('pinned_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (t) => [
    uniqueIndex('story_community_pins_uq').on(t.storyId, t.communityId),
    index('story_community_pins_tenant_community_idx').on(
      t.tenantId, t.communityId, t.pinnedAt.desc().nullsFirst(), t.id.desc().nullsFirst(),
    ),
    tenantIsolationPolicy('story_community_pins_tenant_isolation'),
  ],
).enableRLS();
```
Map: `story_highlights` (nullable `community_id`, `title` + CHECK 1..15 trimmed, `position int >= 0` no unique, `cover_story_id`, `cover_asset_id`, `created_by_user_id`), `story_highlight_items` (unique `(highlight_id, story_id)`, `added_by_user_id`, `added_at`, no `position`), `story_views` (unique `(story_id, user_id)`). Keep the docblock style (the ~40-line "why" block above the table).

## Shared Patterns

### Tenant transaction + emit after commit
**Source:** `packages/core/db/tenant-tx` (`withTenantTx`), used in every service function (`service.ts:1`, `:28-30`, `:329-335`). **Apply to:** all highlight/views service functions. Events queued with `emit` only after `withTenantTx` resolves; ids-only payloads.

### Error vocabulary
**Source:** `ApiError` from `@rede-social/core/server/http/api-error`. One bare `404 NOT_FOUND` for unknown/foreign/removed (no details); `400 VALIDATION_FAILED` with one machine code in `details` (`{ highlight: 'archived' | 'order_stale' }`, `{ story: 'media_invalid' }`).

### Permission guard
**Source:** `routes.ts:356` `middleware: [requirePermission('stories.story.manage')] as const` (literal string, greppable). Web gates via `bootstrap.permissions.includes(STORY_PERMISSIONS.manage)` (UX only).

### Module boundary (MOD-02)
No `@rede-social/module-communities` imports inside `@rede-social/module-stories`: raw SQL on `communities`, hand-written FK, host-injected list bodies (`PinStorySheet.tsx:15-22`). Module-off check: `feed/server/service.ts:390` `if (!(await moduleFlags.isEnabled(ctx, 'communities'))) throw new ApiError(404, 'NOT_FOUND');`.

### UI strings
All copy in `apps/web/messages/pt-BR/stories.json`; module UI takes labels as props; `scripts/check-ui-literals.sh` enforces.

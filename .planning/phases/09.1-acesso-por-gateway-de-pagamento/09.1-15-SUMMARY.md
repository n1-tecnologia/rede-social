# Phase 09.1 Plan 15: The cut screen and the no-access notice Summary

**A member whose payment access lapsed now lands on a calm, branded "Sua assinatura não está ativa" screen from any page, open app or action, with the session kept and one button that fixes it (the link comes from the API per request and is rendered only when `https:`), and anyone refused at sign-up, login or "Participar" reads the same single sentence with an "Assinar" link when the community registered one.**

## Performance

- **Duration:** about 20 min including the reading phase (first gate 09:51Z, last code commit 10:00Z)
- **Tasks:** 3 (Task 1 tracer, Tasks 2 and 3 auto, all `tdd="true"`)
- **Commits:** 5 before this file (3 `test`, 2 `feat`)
- **Files:** 29 touched by the task commits

## Accomplishments

- **Tracer (Task 1).** `bootstrapRedirectPath` maps `SUBSCRIPTION_PENDING` to `/assinatura-pendente?t=<tenant>` (nothing clears the session). The counters BFF recognises both body-carrying refusals through one `refusalFlow` helper and builds the location from the mapping, never from the API body. `LiveShell.landOnPendingFlow` navigates only for that code and a `/assinatura-pendente` path; `onCountersRefused` tries the blocked flow, then this one, on clones of the response. The join and sign-up-and-join actions get the `SUBSCRIPTION_PENDING` branch without `signOutLocally`; the Membros actions get it through the shared mapping. The page reads `GET /v1/me/subscription` per request through `lib/subscription.ts` and draws the title, the body (plus the doubt line when there is no safe link), and the three stacked full-width `lg` actions.
- **Notice (Task 2).** `AccessNotice` (the `UnavailableCard` geometry, `role="alert"`, `Lock` 28, no title, never red, outline `md` "Assinar" only for a safe link) replaces the red line above the sign-up form in both of its states, the red line above the login form, and the form itself on `/participar` for `access_required` (followed by "Verificar de novo" and the decline button). Login reads the host tenant's public record only on the error path; a generic or platform host shows the sentence alone.
- **Secrecy and idempotence (Task 3).** Adversarial cases on every surface: link-shaped query strings, `javascript:`, `data:`, `http:`, `//host`, credentials, over-long values, markup in `?t=`, a second community's name in unrelated fields (refused whole by the strict schemas), byte-identical sentence on sign-up, login and join, the pending page's module imports asserted, `landOnPendingFlow` twice, the mapping a pure function.

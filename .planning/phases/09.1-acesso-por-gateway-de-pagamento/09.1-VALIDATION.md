---

## Sampling Rate

- **After every task commit:** the touched package's Vitest (`pnpm --filter @rede-social/<pkg> test`) plus its typecheck and lint; `pnpm boundaries` when a package import changed; the single pgTAP file when a task is SQL only; the API unit suite (`pnpm --filter @rede-social/api test`) whenever a route is mounted, because it holds the isolation inventory gate.
- **After every plan wave:** `pnpm db:generate` must print "No schema changes", then `pnpm db:reset && pnpm db:seed && pnpm supabase test db` (pgTAP BEFORE integration: residue trips pgTAP 154), then the plan's integration files, and the web unit suites for web plans.
- **Before `/gsd-verify-work`:** `TURBO_CACHE=local:r VIDEO_PROVIDER=fake pnpm verify` green; `pnpm db:reset && pnpm db:seed` before e2e; the three `payments-*.spec.ts` green on `mobile-chromium`.
- **Max feedback latency:** about 120 s for a task's unit sample; integration and e2e samples are per plan.

## Confirmed by the user at plan-checker time (2026-10-20, plan-phase 09.1)

| Id | Decision | Consequence |

## Open questions carried to the owner (not assumptions)

- **Real capture** (plan 20): which of the ten triggers the account can actually produce, and the vendor's real
  signature variant, status vocabularies and mid-period cancel fields. Until then every fixture is a
  documented example and the cancel default is D-496 literal.
- **Hosted environments** (plan 18): the secrets `payments-secret-key-prod` and `payments-secret-key-hml` must
  exist before the push that triggers the deploy; while hml shares production's database the hml secret holds
  the same value as production's.
- **Production hooks** (plan 18): remain disabled until the owner runs the lockout report and flips them by
  hand; no step of this phase enables them.

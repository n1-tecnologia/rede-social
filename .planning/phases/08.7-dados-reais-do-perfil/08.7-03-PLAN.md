1. **Route path.** `GET /v1/dashboard/activity` (inside the dashboard module, MOD-01) instead of the draft `/v1/me/activity`, which would put a module read in the app tier's `/v1/me` group. INSIGHT-01 is worded with the final path.

3. **Deltas computed by the web** from `count` and `previous` as a count difference (`activityDelta` in `apps/web/lib/member-activity-view.ts`: amount = |count − previous|, direction up/down/flat), the shipped member delta kind `count`.
4. **Module flags.** The API omits `byCommunity` with `communities` off and `attendance` with `events` off (flags read before the lane); the web renders absence, not zeros.
5. **Stories seen counts every own `story_views` row of Window7,** including stories deleted afterwards (the member did see them); surfaced as EP-04's reading.
6. **The preview keeps a sample.** UI-D-489 (e): the platform preview is a mock, not tenant data; its sample moves next to it and is excluded from the D-459 guard (plan 12).

- **Found during:** Task 2 (pgTAP before integration)
- **Issue:** The orchestrator expected this pre-existing item to be unrelated to 08.7. The EXPLAIN in the failure output shows the planner on `feed_comments_tenant_created_idx`, which `20261018222400_feed_dashboard_indexes.sql` (08.7-02) created.

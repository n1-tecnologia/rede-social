# Phase 08.7 Plan 11: Atendimento on real data Summary

**The admin's Atendimento now reads the tenant's own support rows from the nightly build, behind the chat gate. It shows the queue at the last update (linked to `/suporte`), the weekly first-response median per member turn with gaps for unanswered weeks, conversations per week, the team's answered conversations by staff name, and Moderação with its removal rate. "Atendimentos por assunto" reads "Em breve". No message text, member name or member id ever leaves the API.**

## Accomplishments

- **`app.dashboard_area_support` and builder v7.** `payload.support` holds counts, minutes and staff user ids only:
  - **`awaiting`.** The inbox rule at build time; `oldestHours` from the first unread member message to the build instant.
  - **`weeklyMedianMinutes`.** Eight blocks of 7 local days ending D, the median per member turn (`percentile_cont(0.5)`, rounded), null for a week with no answered turn.
  - **`weeklyConversations`.** Support conversations by creation week.
  - **`answeredByStaff`.** Distinct conversations per current staff member in Window30, most first.
  - **`moderation`.** Window30 removals, blocks and unblocks (`role_changed` ignored), plus `comments30`.
  - **Posture.** Every predicate pins `app.tenant_id()`; the function is definer with an empty search path and executable by no lane role.
- **`GET /v1/dashboard/owner/support`.** `requireModule('chat')` runs before `requireRole('admin_tenant')`; staff names are joined live as stored; `bySubject` is `{ measured: false, reason: 'needs_support_subject' }`; `Cache-Control: no-store`.
- **The web area.** `OwnerSupport` streams like the other areas, freshness line first:
  - the queue card is a `CardLink` to `/suporte` with "Responder no atendimento", under "Fila na última atualização";
  - the median chart draws gaps for null weeks, with the last-two-weeks chip;
  - the team bars name staff only; Moderação shows the removal rate only when there are comments;
  - "Atendimentos por assunto" is a `ComingSoonBlock` in the `Collapsible`'s place;
  - with chat off the whole area, Moderação included, renders nothing (UI-D-474).

## Decisions Made

Planning decisions 1-3 were followed as written (see `key-decisions`). These choices were made during execution:

- **The oldest wait** runs from the first unread live member message to the build instant, in whole hours, so it matches the inbox's own "awaiting" thread.
- **`comments30`** counts every live comment of the tenant created in Window30. With none, the rate tile and the summary are left out rather than showing 0%.
- **A user no longer staff** since the build is dropped from the team: the answer never names anyone but the current team.
- **An unanswered last week** with earlier answered weeks reads "Nenhuma na última semana" in the median card, never 0.

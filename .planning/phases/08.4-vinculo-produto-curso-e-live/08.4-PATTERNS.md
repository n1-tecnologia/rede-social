## Pattern Assignments

### `packages/modules/store/db/schema.ts` (model, CRUD)

**Analog:** same file, lines 121-141 — clone verbatim, swapping `community` → `course` / `live`:
```ts
export const storeProductCommunities = pgTable(
  'store_product_communities',
  {
    tenantId: uuid('tenant_id').notNull().references(() => tenants.id, { onDelete: 'cascade' }),
    productId: uuid('product_id').notNull().references(() => storeProducts.id, { onDelete: 'cascade' }),
    /** FK to `communities(id) on delete cascade` is hand SQL (fact 4 above). */
    communityId: uuid('community_id').notNull(),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (t) => [
    uniqueIndex('store_product_communities_uq').on(t.tenantId, t.productId, t.communityId),
    index('store_product_communities_tenant_community_idx').on(t.tenantId, t.communityId),
    ...tenantReadAdminWritePolicies('store_product_communities'),
  ],
).enableRLS();
```
Foreign id stays a bare uuid; the FK to `courses(id)` / `course_lives(id)` goes in the custom migration (MOD-02: store must not import courses; `turbo boundaries`).

### `packages/modules/store/server/service.ts` (service, CRUD)

**Validate (lines 113-130)**, one 400 for any miss, no foreign/unknown distinction:
```ts
async function resolveCommunities(tx: Tx, ctx: RequestContext, communityIds: readonly string[]) {
  if (communityIds.length === 0) return;
  const rows = await tx.execute<{ found: number }>(sql`
    select count(*)::int as found
      from communities c
     where c.tenant_id = ${ctx.tenantId}::uuid
       and c.id = any (${uuidArray(communityIds)}::uuid[])
       and c.status = 'active'
       and c.deleted_at is null`);
  if ((rows[0]?.found ?? 0) !== communityIds.length) {
    throw new ApiError(400, 'VALIDATION_FAILED', { store: 'community_invalid' });
  }
}
```
For courses: `from courses` with draft+published allowed (archived refused on a new link); for lives: `from course_lives` excluding `cancelled`. Query by table name (SQL), never import the courses package.

**Read (lines 132-146):** `linkedCommunities` joins link table → entity table on `id` and `tenant_id`, filtered by tenant + product, ordered. Clone as `linkedCourses` / `linkedLives`.

**Create (lines 155-180):** resolve before insert; insert links with
```ts
insert into store_product_communities (tenant_id, product_id, community_id)
select ${ctx.tenantId}::uuid, ${product.id}::uuid, ids.id
  from unnest(${uuidArray(input.communityIds)}::uuid[]) as ids(id)
on conflict (tenant_id, product_id, community_id) do nothing
```

**Replace (lines 596-616):** `replaceLinks` deletes only links to ACTIVE entities (`delete ... using communities c where ... c.status = 'active'`, CR-02 keeps archived links), then the same unnest insert. Clone as `replaceCourseLinks` (keep archived-course links) / `replaceLiveLinks` (keep cancelled-live links).

**Update (lines 640-665):** `lockProduct` (`for update`, 619-626) first, `resolve*` when key present, update columns, `if (patch.communityIds !== undefined) await replaceLinks(...)`, then `readDetail(tx, ctx, productId, true)`; null → `ApiError(404, 'NOT_FOUND')`. Add the two keys alongside.

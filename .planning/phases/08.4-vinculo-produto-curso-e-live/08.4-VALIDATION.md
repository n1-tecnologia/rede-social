## Sampling Rate

- **After every task commit:** Run the touched package's quick run, plus `pnpm supabase test db` when a migration or policy changed, plus the drift check (`pnpm db:generate && test -z "$(git status --porcelain -- supabase/migrations)"`) after any schema edit
- **After every plan wave:** Run `pnpm lint && TURBO_CACHE=local:r pnpm turbo typecheck test`, then `pnpm db:reset && pnpm db:seed && pnpm supabase test db`, then the integration files `store.test.ts courses.test.ts isolation.test.ts store-gate.test.ts platform-tenants.test.ts bootstrap.test.ts modules.test.ts` (pgTAP before integration)
- **Before `/gsd-verify-work`:** Full suite must be green, plus the rehearsal pass and its planted-mismatch fail
- **Max feedback latency:** 120 seconds

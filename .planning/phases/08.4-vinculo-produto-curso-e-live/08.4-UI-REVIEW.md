## Top 3 Priority Fixes

1. **WARNING — "Acesso" product links bypass the discard guard** — `CourseForm.tsx:959` and `LiveForm.tsx:801` render plain `<a href="/loja/{id}">`. The dirty check only runs on the header `X` (`CourseForm.tsx:286`, `LiveForm.tsx:299`), and there is no `beforeunload`. An admin who edits the title and then taps a product name loses the edits with no prompt. Fix: route the click through the same `requestClose` path when the form is dirty (open "Descartar curso?" / "Descartar live?" and navigate on confirm), or add a `beforeunload` guard while dirty.
2. **WARNING — field errors appear off-screen** — the submit button is in the top bar (`ProductForm.tsx:522`), but `course_invalid` / `too_many_*` errors render at the bottom of the form in blocks 5b/5c (`ProductForm.tsx:1257`). No toast fires and nothing is scrolled or focused. `role="alert"` announces the error to screen readers, but a sighted mobile user just sees the save stop. Fix: after `setCourseError` / `setLiveError` (`ProductForm.tsx:371-381`), call `scrollIntoView({block:'center'})` on the block's `[data-product-courses-error]` / `[data-product-lives-error]` node and move focus to its open button.
3. **WARNING — a failed course/live list read is silent in the block** — when `courses.failed` / `lives.failed`, the block still shows "Escolher cursos" with no hint (`ProductForm.tsx:820-865`). The failure only shows up after the sheet opens, where the `EmptyState` uses the same `GraduationCap` / `Radio` glyph as the benign empty state (`CoursePickerSheet.tsx`, `emptyIcon`). Fix: when `failed`, show the tertiary line "Não foi possível carregar os cursos" in the block (or disable the open button with that helper), and give the failed `EmptyState` a distinct glyph such as `AlertCircle`.

## Detailed Findings

### Pillar 1: Copywriting (3/4)
- PASS: every key in `apps/web/messages/pt-BR/store.courses.json` matches the Copywriting Contract verbatim: labels, choose/change, none lines, helpers, picker helpers and capped helpers, row on/off with gender agreement, empty states, the four field errors and the unavailable heading/body. `courses.json:251-254` and `:448` give "Liberado/Liberada pelos produtos" with the gender split from UI-D-418.
- WARNING: "Liberado pelos produtos: {products}" is plural even when a single product links the course ("Liberado pelos produtos: Plano Ouro"). Use an ICU plural: `{count, plural, one {Liberado pelo produto: {products}} other {Liberado pelos produtos: {products}}}`. The same applies to the live line.
- WARNING (inherited, checker FLAG): the sheet footer "Concluir" is a bare verb. It is acceptable in context, but it is the third sheet with this label.
- Minor: the two sheet titles ("Cursos liberados" / "Lives liberadas") repeat the block labels word for word, so the sheet adds no action cue (for example "Escolher cursos").

### Pillar 2: Visuals (3/4)
- PASS: `LinkBlock` (`ProductForm.tsx:1162-1266`) clones the communities block (`:740-812`): the same wrapper, `min-h-11` rows, `X` 18 tertiary and outline `Plus` button. Thumbs use 3:4 at w-8 and 16:10 at w-12 (`THUMB_SHAPE`, `:1047`) with the brand-gradient fallback. UAT confirmed parity at 390px.
- WARNING: see Fix 3. The block gives no visual signal of a failed list read.
- Minor: on a selected row the course title is 14/700, but in the sheet the same title is 14/400 (`CoursePickerSheet.tsx`). The weight change is inherited, but it is a little odd now that the block and the sheet show the same item next to each other.
- Minor: the courses and lives sheets differ only by title and thumb width. A live row with no cover shows the same gradient as a course, so the meta line is the only way to tell the two lists apart.

### Pillar 3: Color (4/4)
- PASS: accent appears only on the picker `Check` (`text-brand`) and the shipped focus rings. Buttons are `outline` / `secondary`, and the product links are `font-bold text-text`, never brand-coloured, as the "explicitly NOT accent" list requires.
- PASS: there are no hex or rgb literals in `ProductForm.tsx` or `CoursePickerSheet.tsx`. The only inline style is `var(--brand-gradient)`, which D-69 sanctions.

### Pillar 4: Typography (4/4)
- Sizes in phase code: `text-sm` (labels, titles, errors, Acesso value) and `text-xs` (meta, none, helpers). Weights: `font-normal` and `font-bold` only. This matches the Typography table exactly.

### Pillar 5: Spacing (3/4)
- PASS: blocks use `gap-2`, rows use `gap-3 min-h-11`, and the blocks sit inside the shipped `gap-6 md:gap-8` stack with no extra hairline (UI-D-413). The sheet uses `pb-2`, `pt-3 pb-4` and `py-2`, as shipped.
- WARNING (inherited): the 12px `gap-3` / `pt-3` is off the 8-point scale. The checker accepted it for verbatim parity, but it is still a deviation.
- The only arbitrary values are `aspect-[3/4]`, `aspect-[16/10]` and `[overflow-wrap:anywhere]`, all declared.

### Pillar 6: Experience Design (3/4)
- PASS: focus after removing a row goes to the next `X`, then the previous one, then the open button (`ProductForm.tsx:1183-1205`, UI-D-421). Field errors clear on toggle (`:483-491`), controls are disabled while saving, the capped helper prevents a silently truncated list, and a failed read keeps the saved rows. The read-only Acesso block is absent in create mode and when no product links the course or live (`CourseForm.tsx:943`, `LiveForm.tsx:785`).
- WARNING: see Fixes 1 and 2.
- Minor: the Acesso links use a raw `<a>` instead of `next/link`, so every jump to `/loja/{id}` is a full document reload.

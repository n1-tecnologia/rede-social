## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| browser/BFF → API | `courseIds`, `liveIds`, product ids and the old `productIds` key on store, course and live routes | attacker-controlled input from any session, including another tenant's |
| host → tenant | a session presented on the other tenant's host | tenant identity |
| API lane → Postgres (RLS) | link writes run in the caller's lane; the four gate bodies are security definer | tenant-scoped link rows, entitlement decisions |
| migration apply → every environment | carry-over, guard, gate swap (file 2) and drop (file 3) run once, before the API revision | course and live link rows, gate answers |
| local rehearsal → local database | the rehearsal resets the local stack twice and restores it | local data only |
| server action → API | the product form's create body and patch | admin form input |
| API → rendered page | course and live titles, product names | tenant content (draft titles are manager-only) |
| developer → hosted environments | DEPLOY.md release steps run by hand | schema/API compatibility |

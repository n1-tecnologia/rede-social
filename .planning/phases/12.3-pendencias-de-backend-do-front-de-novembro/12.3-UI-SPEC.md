# Phase 12.3 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope.** Phase 12.3 draws **no new screen**. The team's merged front (`be6374a3`, branch `ATUALIZAÇÕES-NOVEMBRO`) already shows every surface; this phase makes the backend keep what those surfaces only previewed in the browser. The UI work is therefore a **rewiring contract**: (1) what the web deletes (the provisional cookies, the local previews and every "so neste aparelho" line), (2) how each admin editor now saves (pending, success, refusal, stale), (3) how the second images ("Topo" of a track, a course and a module; the vertical poster of an event) become real, independent uploads, (4) how members read what the admin set (track texts, top covers, "Destaque da loja", "Em destaque", categories, the phone menu), and (5) the copy that changes. Everything else is the front team's design and stays byte for byte.

**Baseline.** Phase 12 / 12.1 / 12.2 UI-SPECs are inherited whole (`12-UI-SPEC.md`, `12.1-UI-SPEC.md`, `12.2-UI-SPEC.md`): Manrope, `#f5f7fb` ground, white cards, 12px radii, 44px targets, the 12/14/16/24 type scale with weights 400/700, the tenant brand as the single accent, `BottomSheet`, `ConfirmDialog`, `Button`, `IconButton`, `Card`, `SegmentedControl`, `useToast`. **Phase 12.3 declares no new token, colour, font, type size, weight, spacing value, icon or dependency.** This file lists only what changes and which merged component each change lands in. **The merged front's own markup, classes and pt-BR strings are the contract; do not restyle or re-word anything this file does not name** (CONTEXT `<specifics>`: "Keep every pt-BR string the team wrote in the UI; only the data now comes from the API").

**Upstream decisions honoured.** `12.3-CONTEXT.md` D-690..D-700 (traced in "How each locked decision shows up"). The visual and interaction questions this phase opens are decided as **UI-D-685..UI-D-696**, continuing after `UI-D-684`, the highest id in any UI-SPEC (`grep -rhoE "UI-D-[0-9]+" .planning | sort -t- -k3 -n -u | tail -1` returned `UI-D-684` on 2026-11-09).

**Non-interactive session.** No question could be asked in this run. Every choice CONTEXT and the merged front left open took a default and is repeated under **To confirm with Igor** (PU-1..PU-7).

**Sketch gate: none recommended (PU-5).** No surface is new and the front team's design (the PDF "O que mudou no front", Part 1) is already merged and typechecked; there is nothing to draw before the executor starts. If Igor wants a look at the one changed composition (the track, course and module top-cover blocks with an independent second image, UI-D-691), it is the single frame worth a sketch.

### `packages/modules/store/db/schema.ts`: `storeCategories`, `storeFront` (model, CRUD)

**Analog:** `packages/modules/courses/db/schema.ts` `courseCategories` (lines 123-141) for the per-tenant list shape; the same file's store-local helper for the policies.

**Imports pattern** (store/db/schema.ts:1-13) already has `check, index, integer, pgPolicy, pgTable, text, timestamp, uniqueIndex, uuid`. Add `uuid().array()` usage (no new import) and `primaryKey` is not needed (`tenant_id` PK is `uuid('tenant_id').primaryKey().references(...)`).

**Policies** (store/db/schema.ts:27-41), the helper is module-local; the new tables go in this same file:
```typescript
const tenantReadAdminWritePolicies = (table: string) => [
  pgPolicy(`${table}_select_tenant`, { for: 'select', to: authenticatedRole, using: SAME_TENANT }),
  pgPolicy(`${table}_insert_admin`, { for: 'insert', to: authenticatedRole, withCheck: TENANT_ADMIN }),
  /* update, delete likewise */
];
```

**Core table pattern** (courses/db/schema.ts:123-141, the one to copy):
```typescript
export const courseCategories = pgTable('course_categories', {
    id: uuid().primaryKey().defaultRandom(),
    tenantId: uuid('tenant_id').notNull().references(() => tenants.id, { onDelete: 'cascade' }),
    name: text().notNull(),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (t) => [
    uniqueIndex('course_categories_tenant_name_uq').on(t.tenantId, sql`lower(${t.name})`),
    ...tenantReadAdminWritePolicies('course_categories'),
  ],
).enableRLS();
```
Adapt: `store_categories(id, tenant_id, slug, name, icon, position, created_at, updated_at)`; unique `(tenant_id, slug)` and `(tenant_id, lower(name))`; `check` icon `~ '^[a-z0-9-]{1,32}$'`; index with `tenant_id` FIRST (040 asserts it). `store_front(tenant_id PK, promo_product_id uuid references store_products on delete set null, featured_product_ids uuid[] not null default '{}' check cardinality<=5, categories_seeded_at, updated_at)`.

**Product column** (store/db/schema.ts:85-123): add beside `imageAssetId` (line 96), `categoryId: uuid('category_id').references(() => storeCategories.id, { onDelete: 'set null' })`. `storeCategories` must be declared above `storeProducts`.

**Gotcha:** FKs must be `set null`/`cascade`, never `restrict`: suites run `delete from public.store_products where name like ...` (store.test.ts:104).

```typescript
async function resolveImageAsset(tx: Tx, ctx: RequestContext, imageAssetId: string | null): Promise<void> {
  if (imageAssetId === null) return;
  const rows = await tx.execute<CoverAssetRow>(sql`
    select kind, purpose, status from media_assets
     where id = ${imageAssetId}::uuid and tenant_id = ${ctx.tenantId}::uuid and deleted_at is null limit 1`);
  const asset = rows[0];
  if (!asset) throw new ApiError(404, 'NOT_FOUND');

}
```

**Source:** `packages/modules/store/db/schema.ts:27-41`. **Apply to:** `store_categories`, `store_front`. Plus `revoke truncate ... from authenticated` (Phase 08.2 CR-01).

**Source:** store `resolveImageAsset` (114-132), courses `resolveCoverAsset`. **Apply to:** every new cover column and the category/promo/featured ids. Unknown or foreign id in a body is a `400` code; in a path a bare `404` (D-23); wrong purpose/kind/status is a `400` code.

### Permission literals
**Source:** `requirePermission('store.product.manage')` (store routes.ts:240) and `KERNEL_PERMISSIONS.tenantManage` (branding.ts:47). **Apply to:** all new write routes; never a role check, never `service_role` for tenant queries.

**Source:** `learnTrackSchema` keys optional (courses contracts index.ts ~1673); `tenantBrandingSchema` `.optional().catch(undefined)`. **Apply to:** every new answer key (strict web parsers reject unknown keys; the bootstrap strips undeclared ones).

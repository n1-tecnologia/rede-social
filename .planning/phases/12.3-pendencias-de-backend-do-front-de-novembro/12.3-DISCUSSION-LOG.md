## Produtos que já existem

| Option | Description | Selected |

**User's choice:** Carga inicial por nome.

| Option | Description | Selected |
|--------|-------------|----------|
| Sim, já nasce com as 8 (Recomendado) | A new store, or one that never touched categories, starts with the eight built-ins, all editable | ✓ |

**Notes:** Evidence shown to the owner before asking: a product with no category sits in no shelf (`store-front-view.ts`), and the web hides this today by guessing from the name; with the server as the source the guess disappears, so the load is what keeps the storefront populated.

It was not asked as a separate question.

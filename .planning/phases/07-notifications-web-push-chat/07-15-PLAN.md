<planning_decisions>
1. **Order web typecheck after web build** with a package task override in `apps/web/turbo.json`. Rejected alternatives:
   - Pointing `next typegen` at a separate dist dir: `next-env.d.ts` would then be rewritten by both commands, so the race moves instead of ending.
   - Making build depend on typecheck: that would add typegen and `tsc` to Vercel's production `turbo build`.
   - Splitting the `verify` script: that loses the CI mirror (`ci.yml` runs the same combined command) unless both are edited.
   - The cost is that root `pnpm typecheck` now builds the web first, which the SUMMARY notes.
2. **Tracer = the gate's own compile stage.** Task 1 proves the edge in the dependency graph and then runs the non-destructive head of `verify` (lint through the lanes guard), so it needs no reset and no consent.
3. **One blocking-human consent, then one full run.** The run resets the local database twice (before `verify` for a fresh integration seed, and `verify`'s own reset before e2e). That wipes rows the developer created by hand, so a `checkpoint:decision` with `gate="blocking-human"` stops in every mode. The same checkpoint asks the developer to stop hand-run servers, since Playwright would otherwise reuse one with a stale environment (the 06-09 pitfall). It also passes on 07-12's note about their own `PLATFORM_HOST`.

   - A new red unrelated to Phase 7 is recorded in `deferred-items.md` with its evidence, and the plan stops.
   - Nothing is skipped, retried until green, loosened or overridden. The override in 07-VERIFICATION is the developer's call.
5. **No schema change: schema push not required.** No package installed; `COVERAGE.md` stands (the api-coverage gate validates it).

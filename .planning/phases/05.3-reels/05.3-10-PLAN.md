<planning_decisions>
1. **One plan, three tasks, tracer first.** Task 1 is the tracer: the like path end to end (host map,
   overlay seed, one remount case, and the browser step in e6). Task 2 expands it to the comment
   count, the lanes and the in-flight races. Task 3 closes WR-01..03. 8 files, at most 5 per task.
2. **Absolute comment count in the host, not a delta.** A lane's first page is fetched on first
   selection, so a lane read made AFTER a comment already counts it; adding a visit delta on top would
   show it twice. The host therefore stores the post's absolute count, starting from the count the
   viewer was shown (the active lane's view) plus the sheet's deltas. The like entry is absolute too
   (the server's pair).
3. **The host's entry wins over later lane reads for the rest of the visit.** A read can predate a
   like that settles before the read lands; letting reads replace entries would race. Other members'
   activity is not live anyway. The next visit starts from the server (UI-D-90's "the next read
   replaces it").
4. **Latest request wins per post in the host** (a request counter keyed by post id), mirroring the
   engine's own `requestId`, so a stale answer never re-seeds a mounted page into a state the viewer
   left, and an answer that lands after its page unmounted is still recorded.
5. **Supersedes one 05.3-08 pattern.** 05.3-08 routed the comment delta through a per-page binder
   "without lifting like state into the host". The binder stays for the like-only double tap; the
   settled like pair and the comment count move to the host.
6. **WR-02: key the player on the credential** (not "hold the old token while mounted"). A neighbour
   that stays mounted while the viewer dwells keeps an ageing token; swiping onto it after expiry
   needs the fresh credential, which a keyed remount delivers and the host restarts through the
   `onController` path it already trusts. A same-credential re-render keeps the element, so the
   synchronous `onActivate` start still finds it. Cost: a current page whose credential is re-minted
   (only after about 110 minutes on one token) restarts from 0, and with sound on outside a gesture

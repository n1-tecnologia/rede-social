# Phase 05.3 Plan 08: The /reels Route and Its Host Summary

**`/reels` is now a real route. It is gated by the bootstrap's module list and server-renders the first "Todos" page and the lanes without any playback credential. `ReelsHost` composes the pager, lanes, `ReelVideo`, one batched credential mint per window change, visit-scoped sound, the OR-ed pause sources, paging and every empty/loading/error state. `ReelOverlay` gives each page the feed's own like engine (a double tap only likes), the linkified caption and share. The feed's one threaded comment sheet sits outside the dark stage. Case e1 passes in both Playwright projects.**

- **Route.**
  - `page.tsx` does `Promise.all` of the bootstrap, both translators and the locale, then `notFound()` outside any try when `reels` is absent. It then loads the first page and the lanes in parallel.
  - It passes ONE resolved label object. The client-filled templates (position, rail author, like plurals) are read with `.raw`.
  - It also passes the feed's like actions and `feedCommentsProps`.
  - It imports nothing token-related.
  - `loading.tsx` is the black `ReelsStage` with a centred `Loader2`.
- **`ReelsHost` (the state machine).**
  - **Lanes:** "Todos" (seeded from the server) plus one lane per community. A lane loads on first selection and is written to its own lane only. Its list is kept for the visit, and it opens at its newest video with `instantKey`. `onLaneStep` is passed only with two or more lanes.
  - **Sound:** `useState(false)` plus `soundOnRef`. The button calls `setMuted` and, when turning sound on, `resume(true)` inside the click. A refusal re-mutes the state.
  - **Gesture:** `onActivate` pauses the current page and calls `start(soundOnRef.current)` on the next page inside the gesture. A `touchend` on the stage wrapper resumes that page once.
  - **Pause:** the viewer, the comment sheet and `visibilitychange` are OR-ed. One transition effect handles them, with `suppressResume` so a gesture that already played does not play twice.
  - **Credentials:** a ref map, a per-asset in-flight set and a generation counter. One `mintReelPlaybackAction` per window change runs before any due load-more.
  - **Paging:** at `loaded − 2`. A failure shows one toast per attempt and the end-swipe retries.
  - **Other states:** the buffering spinner after 500 ms, the sized retry block for a failed video, the empty state (UI-D-94), the stage error (UI-D-93a) and the lane loading state.
- **`ReelOverlay`.**
  - The feed's `useOptimisticLike` wired to the feed's actions. `LikeButton tone="overMedia" glyphSize={28}` shows the announced full count, while the rail draws the compact numbers.
  - `ReelCaption` receives `linkify(caption)`; its expansion resets when the page stops being current.
  - Share is offered only with a `shareUrl`.
  - The `likeOnly` / `bumpComments` binder is registered with the host.
- **Comments.** ONE `CommentSheet` (threaded default variant) is rendered after the stage, outside its dark scope. While it is open, gestures and keys are off and the video is paused. Its count delta reaches the open page's rail.
- **E2E e1.** A demo member taps the Reels tab and lands on `/reels`. On mobile there is no visible TopBar and the BottomNav is `data-theme="dark"`. The region "Reels" shows a `mux-player` whose `tokens.playback` is non-empty (the stream is routed to a handler that never answers), and the sound button reads "Ativar som". ## Decisions Made

- **Sound toggle vs the autoplay check.** See deviation 1.
- **Generation guard semantics.** An answer is dropped for assets that left the window. Assets still in the window keep it, so the current page is never left black by a re-mint after a quick swipe. An incoming token never replaces a held one that expires later.
- **Retry stays until the credential lands.** The failed flag clears when a fresh token is stored, not at the tap. A double tap therefore hits the in-flight guard, and the page shows its error block, never an empty frame.
- **WebKit gesture rule, applied wherever a gesture exists.** Closing the sheet and selecting a loaded lane start or resume inside that gesture. The effect only handles transitions no gesture caused (the background).
- **Requirements.** See the note under Next Phase Readiness.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The sound toggle would have raised a false "autoplay blocked" badge**
- **Found during:** Task 1, while wiring `resume(true)` on the sound button as the plan asks.
- **Issue:** 05.3-07's `play()` reset `played = false` on every call and armed the 400 ms check. A video that is already playing fires no second `playing`, so turning sound on would report `onBlocked` and show the badge over a playing video.
- **Fix:** `played` is reset only when the element is paused, or does not say whether it is (`target.paused !== false`). The existing 24 `ReelVideo` cases are unchanged. A new case failed without the fix, which was verified by reverting the one line, and passes with it.
- **Files modified:** `apps/web/components/reels/ReelVideo.tsx`, `apps/web/components/reels/ReelVideo.test.tsx`
- **Committed in:** 8fb4672

**2. [Rule 2 - Missing critical] A tap on the video retry pill also paused the page**
- **Found during:** Task 1.
- **Issue:** The pill renders inside the pager's `DoubleTapHeart` media slot. Its pointerup would count as a single tap, and the page would pause 300 ms later.
- **Fix:** The block is centred in a `pointer-events-none` box, and a wrapper stops pointer propagation. The rest of the page stays a live swipe surface (REELS-08 adjacency). The badge is not shown over a failed page.
- **Committed in:** 8fb4672

**3. [Rule 2 - Missing critical] Gesture-time play for the sheet close and the lane change**
- **Found during:** Tasks 1 and 2.
- **Issue:** Resuming only from the pause effect would run `play()` a task after the close tap or the lane tap. With sound on, WebKit refuses that and the viewer is silently re-muted.
- **Fix:**
  - `closeSheet` resumes inside the close when neither the viewer nor the background holds the video.
  - `selectLane` starts the lane's first video inside the tap when its element is mounted.
  - `suppressResume` keeps each gesture to one `play()`.
  - A stale `pendingResume` (from a key or wheel move) is ignored while paused.
- **Committed in:** 8fb4672, 7bf4478

**4. [Rule 1 - Bug, test harness] The `motion/react` mock remounted the sheet panel on every render**
- **Found during:** Task 2. Two sheet-ordering cases failed because Escape did nothing after a visibility change.
- **Issue:** The copied proxy mock created a new `forwardRef` component on each `motion.div` access. Any host re-render therefore replaced the dialog node, and the focus trap's Escape listener stayed on the detached one.
- **Fix:** The mock caches one component per tag. It is test-only; the product code is unaffected.
- **Committed in:** 7bf4478

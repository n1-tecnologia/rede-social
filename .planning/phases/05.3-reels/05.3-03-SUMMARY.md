# Phase 05.3 Plan 03: Media chrome in the kernel shell Summary

**On a tab whose nav entry declares `chrome: 'media'`, the shell drops the mobile TopBar and puts the BottomNav under a dark-token scope (`data-theme="dark"`). The kernel reads this from the entry through one shared rule, `activeTabChrome`, and never names `/reels`. The e2e baseline now pins the Reels tab and seven module switches, and is green on 69 tests.**

## Accomplishments

- **`NavItem.chrome`:** `toItem` now carries `chrome` the same way it carries `badge`, only when the manifest declares it. So Início, Perfil, Comunidades and every topbar slot have no `chrome` key at all.
- **`activeTabChrome(tabs, pathname)`:** one exported rule, built on `activeTabKey`, that the TopBar and the BottomNav share. It returns `'media'` on `/reels` and `/reels/abc`, and `null` everywhere else, including on a nav with no media entry.
- **TopBar:** it takes the tab row as an optional `tabs` prop and returns `null` under media chrome. It has no other markup change, and a TopBar rendered without `tabs` always renders.
- **BottomNav:** `data-theme="dark"` is set on the `<nav>` only under media chrome. The attribute is omitted on every other route, so those routes render exactly as before. The docblock no longer says media mode was "deliberately NOT ported". It now describes the declarative dark-token scope and says the collapse mode is still not ported.
- **AppShell:** passes `tabs={nav.tabs}` to both the TopBar and the BottomNav.
- **E2E pins updated in six specs:**
  - demo nav lists gained `'Reels'`, and the lab list became `['Início', 'Reels', 'Perfil']`
  - the feed-only throwaway tenant keeps `['Início', 'Perfil']`, with a note that it has no `reels` row
  - phase2's Feed-off reading now proves that Reels leaves with the feed while its own flag stays on (D-121)
  - `toHaveCount(6)` became 7 in phase2, platform-tenants and platform-domains, and the platform-domains loop and "Ativado" count became 7 too

## Decisions Made

- `activeTabChrome` goes through `activeTabKey`. The media tab therefore keeps its chrome on sub-paths, and the longest-match / first-tab-wins rule stays the only definition of "active".
- Media chrome is a dark-token scope on the `<nav>` alone. `.glass-bar`, the active chip (`--theme-chip`) and the active icon (`--brand-accent` → `--brand-primary-dark`) all re-resolve from the dark block that already ships, with no new token.
- The Feed-off reading in phase2-smoke asserts the D-121 consequence (Reels leaves) rather than a list with Reels in it (see deviation 1).

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| browser → web → `GET /v1/feed?media=video&communityId=…` | An authenticated caller supplies the filter and a community id, both untrusted | tenant-scoped post and community ids |
| browser → web → `GET /v1/feed/video-communities` | An authenticated member asks which communities have videos | community names and slugs |
| API composition → bootstrap / permissions | `effectiveKeys` decides what a tenant's enabled flags contribute; the shell and every `requirePermission` trust it | module keys |
| API service → Postgres | `api_user` under `set local role authenticated` inside `withTenantTx`; RLS plus explicit tenant predicates | tenant rows |
| migration → live database | The `reels` backfill writes one row per existing tenant on first apply | module flags |
| bootstrap nav entry → kernel shell | The shell trusts the server-composed nav entry's `chrome` | nav metadata |
| review artifact / human approval → agent execution | Sketch 005 must never become a runtime dependency, and the approval must come from the user | design mockup, approval lines |
| viewer input (pointer, key, wheel) → pager | Untrusted input rate and shape | gestures |
| admin-authored caption and community names → rendered DOM | Text written by an admin (V1) and, in Phase 9, by members | untrusted text |
| browser → `mintReelPlaybackAction` → API `/v1/media/{id}/playback` | The client names asset ids; bearer playback credentials are minted per request | asset ids, short-lived playback tokens |
| vendor player → screen | Player and provider error messages | error text |
| client host → server actions (pages, mint, like, comments) | Every action re-validates input and goes through the API's tenant lane | post ids, cursors, likes |
| visit-scoped client state (sound choice, token map, per-post interaction map) | Must not outlive the visit or reach storage | tokens, like pairs |
| member-controlled display name → pager live region | Text interpolated into an `aria-live` region | display names |
| e2e fixtures → shared local database | Specs write rows the seed-pinned specs also read | test rows |

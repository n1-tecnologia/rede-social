**Decision recorded — alias scoping in tokens.css.** CSS custom properties substitute `var()` where they are DECLARED, not where they are used: `--brand-accent: var(--brand-primary)` declared on `:root` computes once on the root and is inherited as that value, so a `--brand-primary` set inline on a wrapper (02-01's auth `<main>`, 02-07's `[data-brand-root]`, this plan's mini-shells) never reaches `bg-brand` unless the alias is re-declared on that wrapper. The BrandPreview makes this unmissable (two frames, two themes, one page), so this plan carries the one-file fix in `tokens.css` and proves it by computed style in Playwright. 02-02's `tokens.test.ts` greps must keep passing (the `:root` fallbacks and the `[data-theme="dark"]` neutral block stay where they are; only the alias declarations gain scoped selectors).

**Decision recorded — worker under e2e.** Icon derivation runs only in the `ROLE=worker` process (02-13). `apps/web/playwright.config.ts` is owned by 02-16 and starts API + web only, so this spec spawns (or reuses) a worker itself through `apps/web/e2e/worker.ts`; the helper is handed to 02-16 for the smoke.

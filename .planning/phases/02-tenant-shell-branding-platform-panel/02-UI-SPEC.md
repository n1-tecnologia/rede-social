# Phase 02 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Design authority.** `reference/frontend-design/` (git `05f68b1`) is the visual source of truth for everything it covers (member shell, auth pages, primitives). Values below marked **[proto]** are extracted verbatim from it. Screens the prototype lacks — the platform panel (`/plataforma/*`), the desktop shell, accept-invite, suspended/offline pages, the iOS install hint — are marked **[designed]** and use only the prototype's tokens and primitives. Decisions from `02-CONTEXT.md` are cited as **D-nn**; `02-RESEARCH.md` patterns as **R-Pn**.

**Review pattern (D-33, UI-04).** This document is the contract; `/gsd-sketch 2` renders the `[designed]` screens as a static HTML mockup from it; the design team approves the mockup before those screens are coded. The plan models that approval as a human-verify checkpoint off the critical path (schema, API, adapters, primitives first).

## Spacing Scale

Declared values (must be multiples of 4) — **[proto]** the prototype's gutter is `px-4`, list gap `gap-3`, section gap `mb-6`, controls `py-3`:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps inside chips/badges, hairline offsets |
| sm | 8px | Gap between inline controls, chip rows, BottomNav bottom offset (`+ safe-bottom`) |
| md-s | 12px | List/card gaps (`gap-3`), input vertical padding, table cell vertical padding |
| md | 16px | Page gutter (`px-4`), card padding, form field gap, TopBar horizontal padding |
| lg | 24px | Section spacing (`mb-6`), desktop content gutter (`px-6`), dialog padding |
| xl | 32px | Auth page block gap, panel section gap on desktop, EmptyState top padding pair |
| 2xl | 48px | TopBar height (`h-12`), rail logo box height, desktop content top padding (`pt-12`) |
| 3xl | 64px | EmptyState icon circle, EmptyState vertical padding (`py-16`), login logo box |

Exceptions (all documented, all from the prototype or platform HIG):
- **44px** minimum touch target for icon-only controls (`IconButton`, back buttons, BottomNav chips `h-11`), Apple HIG / WCAG 2.5.5.
- **18px** count `Badge` diameter (fits the 44px control corner).
- **50px** BottomNav tab chip width (`w-[50px] h-11`) **[proto]**.
- **14px** BottomNav horizontal inset (`left-3.5`, width `calc(100% - 28px)`) **[proto]**.
- **14px** `py-3.5` vertical padding of settings rows and the ConfirmDialog footer buttons; `px-3.5` horizontal padding of `Chip`/`StatusPill`; `left-3.5` inset of the `Input` leading icon **[proto]** — rendered verbatim, not normalised.
- **6px** `py-1.5` vertical padding of `Chip`/`StatusPill` and of BottomNav tab links; `px-1.5` BottomNav pill inner horizontal padding **[proto]**.
- **2px** hairline geometry, not layout spacing: `IconButton` badge offset (`-top-0.5 -right-0.5`), `Tabs` active underline thickness (`h-0.5`), `Switch` track inner padding (`px-0.5`) **[proto]**; 1px/2px borders and rings (`border`, `border-2`, `ring-1`) are stroke widths and fall under the same rule.
- **56px** table row min-height and mobile list row height (multiple of 4 — listed for clarity).
- **240px** desktop rail width; **680px** content column max width (D-39 range 640–720); **1040px** platform-panel content max width.
- Every arbitrary `max-w-[…]` in this spec (260, 300, 360, 420, 480, 680, 1040) is a multiple of 4; icon sizes (18/20/22/23/24/28/40) are glyph sizes, not spacing.

## Typography

Font: Manrope only. Sizes and weights are the four sizes and two weights the prototype actually uses most (`text-sm` 244×, `text-xs` 138×, `text-base` 35×, `text-2xl` 14×; `font-bold` 202×, `font-semibold` 125× — the 600 usages collapse to 700 on port, the `font-medium` labels to 400).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Caption | 12px | 400 (700 for chips, uppercase section micro-headers `tracking-wider`, table headers) | 1.5 | Meta text, helper text, status pills, table headers, BottomNav has no labels |
| Body | 14px | 400 (700 for emphasis: button labels, list titles, tab labels, dialog footer) | 1.5 | Default body, form labels (`text-text-secondary`), settings rows, table cells, toasts |
| Body-L / Heading | 16px | 400 for inputs and long-form body; 700 for headings | 1.5 (body) / 1.2 (headings) | **All inputs (iOS zoom guard)**, sheet/dialog/EmptyState titles, TopBar tenant name, rail nav labels stay 14 |
| Title | 24px | 700 | 1.2 | Page titles (`Configurações`, `Tenants`, `Novo tenant`), login/accept-invite display-name heading, `letter-spacing -0.02em` (**[proto]** `.heading-serif`) |

Exception: the numeric count inside `Badge` is 10px/700 (non-prose numerals inside an 18px circle) **[proto]**. No other size is permitted; the prototype's `text-lg` (18) titles normalise to 16/700 and the login `text-3xl` (30) to 24/700.

`tabular-nums` on every number column (counts, dates, DNS TTLs).

## Color

Two-layer model kept **[proto]**: raw `--theme-*` (light on `:root`, dark on `[data-theme="dark"]`) and tenant `--brand-*` set server-side on `<html style>`/`<body style>`; utilities read them through `@theme inline` (R-P2). Neutral values are the prototype's, verbatim.

|------|-------|-------|

| Secondary (30%) | `--theme-bg-secondary` `#ffffff` / `#181c26` (= `--theme-card`, `--theme-bg-elevated`) | Cards, TopBar, desktop rail, sheets, dialogs, table container, form panels; `--theme-bg-tertiary` `#e9eef7` / `#232937` for secondary buttons, avatar fallback, Skeleton; `--theme-bg-input` `#eef2f9` / `#232937` for inputs and idle chips |

| Brand secondary | `--brand-secondary` (tenant hex; fallback `#5b9cf8`) | **Only** the second stop of `--brand-gradient` (CTA `variant="brand"` hero use on auth pages) and the maskable-icon ring; never as text or a second accent |

Accent reserved for: (1) `Button variant="brand"` fills and the auth-page CTA gradient; (2) the active BottomNav tab icon and the active rail item icon+label; (3) the active `Tabs` underline and active `Chip` fill; (4) text links and `ghost` button text; (5) input focus border + ring; (6) `Switch` on-state track; (7) the "Primário" pill and the `SectionTitle` micro-header; (8) the `PullToRefresh` loader and info toast; (9) `theme_color` in the manifest/viewport and the maskable icon background; (10) the ConfirmDialog non-danger confirm label and icon tint. Everything else — cards, rows, TopBar, rail background, table headers, secondary buttons, idle icons — is neutral. Brand never colours body text, borders, or page backgrounds.

Derived tokens (never enumerated per tenant, D-25): `--brand-primary-hover: color-mix(in oklch, var(--brand-primary), black 12%)`, `--brand-primary-soft: color-mix(in oklch, var(--brand-primary), white 88%)` (dark: `color-mix(…, #0f1118 80%)`), `--brand-gradient: linear-gradient(135deg, color-mix(in oklch, var(--brand-primary), black 15%), var(--brand-primary), var(--brand-secondary))`.

Contrast rule (R-P2): panel save validates in **both** modes — `onPrimary` vs `primary` ≥ 4.5:1 (else warn), `primary` vs `#f5f7fb` ≥ 3:1 and `primaryDark` vs `#0f1118` ≥ 3:1 (else warn). Warnings never block; they require an explicit "Confirmar mesmo assim" (D-Discretion).

## Motion & Accessibility

- Easing: BottomNav `cubic-bezier(0.2, 0.715, 0.205, 0.99)`; springs — BottomSheet `damping 28 / stiffness 300`, ConfirmDialog `stiffness 380 / damping 26`, Toast `damping 22 / stiffness 300` **[proto]**; colour transitions `150–200 ms ease`. `prefers-reduced-motion: reduce` disables springs (instant opacity) and the Skeleton shimmer.
- Focus: replace every `focus:outline-none` with `focus-visible:ring-2 ring-brand ring-offset-2 ring-offset-bg`; never remove focus without a visible replacement.
- Roles: `BottomSheet`/`ConfirmDialog` `role="dialog" aria-modal="true"` + focus trap + Escape; `Tabs` `tablist/tab/tabpanel`; `Switch` `role="switch"`; BottomNav `aria-current="page"`; toasts `role="status"` (`aria-live="polite"`), errors `role="alert"`.
- Viewport: pinch-zoom allowed (no `maximumScale: 1` / `userScalable: false`) — deliberate departure from the prototype (WCAG 1.4.4).
- Images: tenant logo `alt={displayName}`; decorative icons `aria-hidden`.
- Copy-to-clipboard confirms both visually (icon swap) and via `aria-live`.
- Hydration: no `Date.now()` in render; dates formatted with `Intl.DateTimeFormat('pt-BR', { timeZone: tenant.timezone })`.

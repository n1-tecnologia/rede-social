## Decisions Made

- **`=0` plural forms on the count metas.** pt-BR CLDR places 0 in the `one` category, so the contract's literal `{N, plural, one {# aula} other {# aulas}}` rendered "0 aula" and `courses.row.meta` "0 módulo · 0 aula". `courses.row.meta`, `metaWithDuration`, `courses.curriculum.module.meta` and `metaWithDuration` gained `=0 {# módulos}` / `=0 {# aulas}`; the i18n test pins "0 módulos · 0 aulas" and "0 aulas". The one/other wording of the contract is unchanged.
- **`HubTabs.tsx`.** The shipped `Tabs` is `'use client'` and requires an `onChange` function; a server page cannot pass one. A nine-line client wrapper owns `onChange → router.push(item.href)` and renders the `href` items; `tabs.ts` stays a plain `.ts` the page, the wrapper and later plans share.
- **The page repeats the gate.** The first Playwright run logged `courses.list_failed { status: 403 }` for every member case: Next renders the layout and the page concurrently, so `CoursesTab`'s two reads fired before the layout's `notFound()`. `page.tsx` now checks the same cached bootstrap and calls `notFound()` before rendering the tab; the layout remains the authoritative gate for every `/cursos/*` child.
- **First-load error in the client list.** The plan's action text suggested a server-rendered "Tentar novamente" link to the same URL; `CoursesList` renders the `EmptyState` card with an `outline` `Button` that re-reads page 1 through `refreshCoursesAction` (the `ProductGrid` shape), so first load, pull-to-refresh and load more share one state machine. The truth (the card, the copy, the outline retry) holds either way.
- **A throwaway tenant per e2e project.** The three Playwright projects run in parallel against one database; "Nenhum curso ainda" on rede-demo would read a sibling project's fixtures and a module flip would sit in the API's 30 s cache shared by the suite. `createCoursesTenant('e2e-cr-<project>', …)` (the events-admin shape) carries every emptiness, fixture and flip; the seed tenant proves only the door, the hub frame and the member's not-found.
- **`check-static-routes.sh` not run locally.** It exits 2 without a build and the orchestrator ruled out `next build` for disk; the stale `.next` on disk (20:11, before `/cursos`) would only report the new REQUIRED_KEYS entry as "route moved". The key is added, every `/cursos` page reads `requireBootstrap()` like `loja`, and the gate runs in CI's `pnpm verify`. Recorded in `WINDOWS.md` (`unrun-verify`).
- **Requirements left Pending.** `requirements.ready-ids` answers 0/2: COURSE-01 is shared with plans 01 and 12, COURSE-14 with 02, 07, 08 and 09; they flip when the last declaring plan finishes.

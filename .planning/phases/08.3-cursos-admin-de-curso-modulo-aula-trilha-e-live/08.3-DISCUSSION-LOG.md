## Aula: vídeo, materiais, tipos

### Toda aula tem vídeo? De onde vem?
| Option | Description | Selected |
|--------|-------------|----------|
| Vídeo opcional, só upload Mux | Aula pode ser texto + materiais; playback assinado; sem YouTube | ✓ |
| Vídeo obrigatório, só Mux | Toda aula é um vídeo | |
| Mux ou link externo (YouTube/Vimeo) | Link não respeita o cadeado | |

**User's choice:** Free text first: asked whether Mux would be too expensive and what the cost progression is; then whether an S3 bucket would be cheaper. Claude presented Mux list prices (encoding free at 1080p basic, storage US$ 0.003/min/month, delivery US$ 0.001/min after 100k free minutes), three scenarios (pilot ~US$ 24/month, medium ~US$ 270, large ~US$ 1,140), Cloudflare Stream parity at scale, and the S3 comparison (CloudFront US$ 0.085/GB makes delivery ~3x Mux at 1080p; no transcoding; MediaConvert ~US$ 0.05/min; pipeline would have to be rebuilt). User: "seguimos com mux então". Recorded as the recommended option (video optional, Mux only).
**Notes:** Sources: mux.com/pricing, developers.cloudflare.com/stream/pricing, aws.amazon.com/mediaconvert/pricing, third-party CloudFront rate cards.

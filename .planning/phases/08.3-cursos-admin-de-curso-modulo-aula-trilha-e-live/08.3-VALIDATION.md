## Sampling Rate

- **After every task commit:** Run the touched package's quick run (`module-courses` / `api` unit / `core` `tests/media` / `web` vitest), plus `pnpm supabase test db` when a migration or policy changed
- **After every plan wave:** Run `pnpm lint && TURBO_CACHE=local:r pnpm turbo typecheck test`, then `pnpm supabase test db`, then the phase integration files (`courses.test.ts isolation.test.ts media.test.ts media-playback.test.ts mux-webhook.test.ts platform-tenants.test.ts bootstrap.test.ts modules.test.ts`); `pnpm db:reset && pnpm db:seed` between runs if a run left residue
- **Before `/gsd-verify-work`:** Full suite must be green; the two-tenant isolation suite (SC 7) is the exit gate
- **Max feedback latency:** 120 seconds for the per-task quick run

# Phase 08.3 Plan 08: The course page, the curriculum editor and the module sheet Summary

**The admin assembles and publishes a course on `/cursos/{courseId}`: module cards and lesson rows reordered by always-visible arrows that write the parent's whole order on every tap (restore on failure, refresh on `order_stale`), a module sheet with the sequential-lock switch disabled on the first module, and a publish zone whose warning card names the lessons still processing above a disabled "Publicar curso" — with the server's `409 video_not_ready` re-drawing that card from its own lesson ids.**

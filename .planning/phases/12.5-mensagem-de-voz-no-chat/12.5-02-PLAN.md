## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to Storage | untrusted bytes written to a private key through a signed URL |
| API request path to the worker | the request path reads 16 bytes only; the worker decodes |
| worker to ffmpeg | a hostile container or stream reaches a native decoder |

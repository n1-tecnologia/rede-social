## Pattern Assignments

### `app.chat_asset_hidden` seam (migration + `chat-gate.ts`)

**Kernel stub analog:** `20261015194744_course_asset_gate_seam.sql` lines 27-31 (copy verbatim, rename):
```sql
create or replace function app.course_asset_hidden(p_asset uuid) returns boolean
language sql stable security definer set search_path = '' as $$ select false $$;
--> statement-breakpoint
revoke all on function app.course_asset_hidden(uuid) from public;--> statement-breakpoint
grant execute on function app.course_asset_hidden(uuid) to authenticated;
```
The header comment states the hardening posture: SECURITY DEFINER, `search_path = ''`, fully qualified names, EXECUTE revoked from PUBLIC and granted to `authenticated`, expand-only stub that reads no table.

**Body analog:** `20261111150352_story_media_gate.sql` line 44 `create or replace function app.media_asset_hidden(p_asset uuid)` (the module gives the body with `create or replace`, same signature). Chat body: hidden unless the caller is a participant of the conversation holding the message that owns the asset (and, for the member lane, within the tenant).

**TS wrapper:** `packages/core/db/course-gate.ts` lines 57-61:
```ts
export const courseAssetHidden = (assetId: string): SQL =>
  sql`app.course_asset_hidden(${assetId}::uuid)`;
```
Header doc style: kernel NAMES the gate, the module gives the body, consumers import only this file. Mirror `community-gate.ts` (39 lines) for the file layout.

### `packages/core/server/media/derive-job.ts` (audio branch)

**Imports (lines 1-13):** `withAdminTx` from `../../db/admin-tx`, `mediaAssets` from `../../db/schema`, `enqueueInTx` from `../jobs/boss`, `moduleLogger`, `JobDefinition`, payload schema and `MEDIA_DERIVE_*` constants from `./index`, `deriveAssetVariants` from `./service`.

**Core pattern (lines 69-147):** handler never throws; `safeParse` the payload, drop on malformed; try `await deriveAssetVariants(tenantId, assetId)`; on error log, and while `attempt < MEDIA_DERIVE_MAX_ATTEMPTS` call `requeueVariantDerivation` (singletonKey = assetId, `startAfter: 30 * attempt`); at the cap call `markDerivationFailed` which conditionally updates `status='failed', failureReason='derive_failed'` where status in `pending|processing` (an asset is never left `processing` forever). The audio branch (ffmpeg transcode and duration probe) should live in the service function the job calls, reusing these failure writes unchanged. The worker role runs it (`apps/api/src/worker.ts` lists it).

### `inspect.ts` (offset-aware signatures)
**Pattern (lines 105-133):** `inspectFile(buf, declaredMime)` dispatches images to sharp, else compares `FILE_SIGNATURES[declaredMime]` with `buf.subarray(0, signature.length)` and throws `new MediaImageError('format_mismatch')`. `fileSignaturePrefixBytes(mime)` returns the ranged-read size (`FILE_SIGNATURE_PREFIX_BYTES = 16`, `null` for sharp-decoded images). For audio (e.g. `ftyp` at offset 4 for m4a/mp4, `OggS`, EBML `1A45DFA3`, `RIFF....WAVE`), extend the signature table with an offset field and raise the prefix bytes enough to cover it (e.g. 16 already covers offset 4 + 4; check WAVE at offset 8).

### Web upload (`useSignedUpload.ts`, `lib/upload.ts`, `sw.ts`)
`useSignedUpload({ kind, purpose, onCompleted, maxBytes, tooLargeMessage, ... })` is the state machine `classify -> start -> browser PUT/TUS -> complete -> done`; the server actions carry `{ kind, purpose, mime, size, filename }` and an `assetId`, never bytes. Use `MEDIA_LIMITS[kind][purpose]` for caps and `formatMediaLimit` for copy (never hard-code a number). Pick is try/catch only, no `finally` (WR-07); raw errors go to the console and the member sees a catalog string. Add the new `{ kind: 'audio', purpose: 'voice' }` to the shared `@rede-social/contracts/media` table. Read `sw.ts` for the runtime-caching rules before deciding how audio object URLs are cached (signed URLs must not be precached).

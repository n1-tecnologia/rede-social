## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to the two server actions | a server action is a public endpoint: its arguments are untrusted |
| take bytes to the signed Storage URL | the file is the member's own and goes straight to Storage |
| service worker to the media request | a worker in the path of a media request can break or replay it |

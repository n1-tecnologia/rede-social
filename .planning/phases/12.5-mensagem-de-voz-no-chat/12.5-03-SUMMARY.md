## Deviations from Plan

### Measurement adjustments

**1. [Plan shape] The baseline came from a throwaway Dockerfile copy, not from commenting the line out**
- **Found during:** Task 3
- **Issue:** The plan says to comment the line out temporarily; doing so in the repository risks an uncommitted broken Dockerfile.
- **Fix:** Built the baseline from a copy in the scratchpad with the `RUN` stripped, same build context and target. The committed Dockerfile was never changed.
- **Files modified:** none in the repository.

**2. [Plan shape] The cold-start reading is a proxy, not the application's own log line**
- **Found during:** Task 3
- **Issue:** `ROLE=api` needs `DATABASE_URL` and the rest of the environment; without a live stack it exits at environment validation, so there is no "listening" line to read. Supplying real credentials was out of bounds (no hosted project, no local stack touched).
- **Fix:** Measured wall time of `docker run --rm -e ROLE=api` to exit (container creation, node boot, bundle load, env validation), five runs per image. This captures image-level start cost only; ffmpeg adds files, not start-up work.
- **Owner row:** the real Cloud Run cold start of the rebuilt revision is read at release time (plan 18): compare the first-request latency of the new `api` revision with the previous one in Cloud Run metrics.

**Total deviations:** 2 plan-shape adjustments, no behaviour or scope change. **Impact:** none on the decision; the size delta that drives the rule is exact.

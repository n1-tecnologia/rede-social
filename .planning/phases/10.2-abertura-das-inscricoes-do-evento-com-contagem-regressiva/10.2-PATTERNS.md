## Shared Patterns
- **Single decider / DB clock:** only `app.event_checkout_url` decides the link; `serverNow` is `now()` of the same statement.
- **Definers:** `security definer set search_path = ''`, tenant pinned with `app.tenant_id()`, explicit `revoke ... from public, anon` + grant; `service_role`-only variants for cross-tenant job lanes.
- **Expand-only + `.optional()` on every new response key:** old API/web keep working; free events keep byte-identical payloads (spread only when `paid`).
- **Closed machine codes:** `EVENT_ISSUES` + `checkViolation()` constraint-name mapping, never string-matching messages.
- **MOD-02:** events and payments never import each other; cross-module effects go through SQL definer names.
- **Web:** pure view models, plain serializable data, nodes only in client islands; no gateway brand names in new identifiers or catalogs; strings via next-intl ICU in `events.json`.

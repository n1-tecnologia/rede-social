## Sampling Rate

- **After every task commit:** the touched package's Vitest, typecheck and lint; `pnpm boundaries` when an import changed; the single pgTAP file for SQL-only tasks.
- **After every plan wave:** `pnpm db:generate` prints "No schema changes", then pgTAP **before** integration, then the plan's integration files, then the web unit suites, then `move-copy.test.ts` once after the schema plan.
- **Before `/gsd-verify-work`:** `TURBO_CACHE=local:r VIDEO_PROVIDER=fake pnpm verify`; `next build` once; `events-opening.spec.ts` and the existing `events-tickets.spec.ts` green on `mobile-chromium`.
- **Max feedback latency:** ~120 seconds for the per-task command.

## Phase Goal

**As an** `admin_tenant`, **I want to** run my community from my phone (brand, members and roles, moderation and community rules), **so that** every action takes effect immediately, is logged, and the pilot can pass its go-live gate. Each slot is taken from the ROADMAP Phase 8 Goal line.

<objective>
The isolation half of the go-live gate (ROADMAP SC 4, D-344). Every endpoint, every storage-minting route and every Realtime topic kind gets a cross-tenant negative test, and a machine check makes that coverage permanent. The route table is the inventory, so a future route cannot ship without its case.

**Plan story:** **As the** platform owner, **I want** proof that no route, file or live channel can show one community's data to another, **so that** the core promise (zero leakage between tenants) holds at go-live and stays true afterwards. Taken from ROADMAP SC 4, TENANT-05 and the core value.

Requirement mapping: the `phase 8 sweep` is the cross-tenant proof of MODER-01..03 and ADMIN-01..03's new endpoints.
Claude's Discretion "Isolation suite breadth": a route-inventory assertion plus a web route-handler inventory, so a missing case fails the build.
Purpose: make "every endpoint" a checked statement, not a promise.
Output: the API and web inventories with their unit checks, the Phase 8 sweep, and the Realtime and storage cross-tenant cases.
</objective>

## Phase Goal

**As an** `admin_tenant`, **I want to** run my community from my phone (brand, members and roles, moderation and community rules), **so that** every action takes effect immediately, is logged, and the pilot can pass its go-live gate. Each slot is taken from the ROADMAP Phase 8 Goal line.

<objective>
ADMIN-03. The admin edits the community rules that new members read and accept at sign-up. The editor previews exactly what `/cadastro` shows, and a save bumps the consent version only when the text changed (D-341). The Configurações admin group is complete after this plan (D-339).

**Plan story:** **As an** `admin_tenant`, **I want to** write and update my community's rules and see them as a newcomer will, **so that** everyone who joins from now on agrees to the current rules. Taken from ADMIN-03 and D-341.

Claude's Discretion "The rules editor format": plain text, with blank-line paragraphs and kept single line breaks, rendered by one shared component, because that is how `/cadastro` already renders rules.

Purpose: give the admin control of the rules without ever rewriting a recorded consent.
Output: the rules service and routes, the shared `RulesText`, the Regras screen with its preview, and the tests.
</objective>
